# 從書架開書不做封面放大轉場

從書架點書開閱讀器，用 `BookOpenRoute` 的短淡入加輕微上滑，不做「書卡封面放大翻開成閱讀頁」。2026-10-14 曾做過封面放大（`d96c0cc`），使用者在實機上看過後要求移除：書架封面是縮圖，放大到整頁時畫質很差；而且封面放大結束時正文常常還沒準備好，接著仍然看到載入轉圈，轉場沒有真的把等待藏起來，反而多了一段。

## Consequences

- 封面的共享元素轉場（Hero）只用在清單與書籍詳情之間（書架、發現、搜尋 → 詳情），兩端的封面尺寸接近，不會放大失真。
- 之後若要重新考慮開書轉場，前提是閱讀器在轉場結束時已經能直接顯示正文（見閱讀器開書流程），並且有可放大的高解析封面。
