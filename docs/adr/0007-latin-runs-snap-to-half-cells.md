# 英數字段補到半格，emoji 佔一格

正文以字格對齊（ADR 0005）：文字框寬度是整數個字格，漢字與全形標點各佔一格。英文、數字與半形符號用的是比例寬度的西文字型，夾在一行裡時，那一行後面的字就離開直行，右緣也短一截。2026-10-13 起，換行引擎（`VisualLineLayoutEngine`）把連續的非整格字合成一段，寬度補到半格的整數倍，補白平分兩側（鄰接漢字或 emoji 的一側至少 1/8 格，接近 W3C《中文排版需求》的中西文間隙；鄰接全形標點不另外留）；行首的一段貼齊左邊界、行尾的一段不補右側。emoji 縮到剛好一格寬，每一行的行高用 strut 固定。中英文之間原有的半形空格在顯示時拿掉，間隙一律由補白提供。

## Considered Options

- 補到整格：直行完全對齊，但英數字兩側最多空出將近一格，顯得鬆散；選了半格，代價是英數字之後的字可能錯開半格，到下一行才回到直行。
- 左右對齊（justify）攤平空隙：Flutter 的排版引擎只拉開空白、而且不處理強制換行的行，中文正文做不到，開關已刪除（`d008573`）。
- 長英文單字逐字母斷行讓右緣切齊：會把單字切開，維持整字換行。

## Consequences

- 補白記在換行計畫裡（`ChapterBlock.visualLineSpacers`），Paragraph 以零高度的 placeholder 畫出；選字、朗讀高亮與閱讀位置都經 `ParagraphTextMap` 跳過它。
- 改動這套規則要提高 `kReaderV2CjkTypographyFeatureSignature`，舊的量測與換行快取才不會沿用。
