# 離開時蓋住畫面、解鎖才能打開

使用者 2026-11-24 要的：「加入進入後台模糊功能以及相關權限功能」。看過舉例後選了「離開時蓋住畫面」與「解鎖才能打開」，不做「禁止截圖與錄影」。Legado 兩項都沒有，夜讀自己定。

## 決定

- **兩列設定，放「關於夜讀」新的一段「隱私」**（ADR 0030：App 本身的設定在「關於夜讀」；「我的」第一層維持九個入口）：「離開時蓋住畫面」開關，預設關；「解鎖才能打開」三選一：不鎖（預設）／離開就鎖／離開 5 分鐘後。解鎖開著時畫面一定蓋住，第一列跟著打開、灰掉。預設最克制（產品界線 6）。
- **蓋住的樣子照平台做得到的**：
  - iPhone：離開時（含拉下控制中心、通知中心）蓋一層模糊，看得出是夜讀、看不出字；模糊由系統畫，不等 Flutter 的一幀。回來時模糊淡掉。
  - Android 13 以上：請系統不要拍多工畫面的縮圖，縮圖是夜讀的底色加圖示，不是模糊。Android 在離開的瞬間拍縮圖，夜讀畫的模糊來不及，各家手機的時間點也不同。
  - Android 12 以下：離開時暫時把視窗設成不能截圖，回來就拿掉；盡力蓋，有的手機照樣拍到原畫面，不另外處理。
  - Android 分割畫面時，點另一邊的 App 不蓋（夜讀還在畫面上）。
- **什麼算離開**：回到桌面、切到別的 App、從多工畫面離開、夜讀被系統收掉。Android 關螢幕不算：手機自己的鎖已經擋著，回來不用解兩次鎖；iPhone 分不出關螢幕與離開，照離開算。
- **夜讀自己打開的系統畫面不算離開**：選檔案、選封面圖、分享、用瀏覽器開登入網址、登入 Google 雲端硬碟、系統的權限設定、安裝更新、解鎖用的手機密碼畫面。記號只在打開後馬上離開時用掉，回來就清掉；沒用掉的記號不留給下一次真的離開，拿不準時照離開算。
- **什麼時候鎖**：「離開就鎖」每次離開回來都要解鎖。「離開 5 分鐘後」每次離開都先蓋上鎖的畫面，回來時照離開多久決定：不到 5 分鐘直接拿掉、不用解鎖；時鐘倒退時照超過算。夜讀被系統收掉、重新打開時，只要開著就一定要解鎖。
- **怎麼解鎖**：用手機本身的指紋、臉或鎖屏密碼，跳出系統的辨識框；辨識失敗幾次改輸入手機密碼。夜讀不另外設密碼，沒有「忘記密碼」。手機沒設鎖屏密碼、或 Android 8 以下（系統辨識框要的佈景夜讀沒有用）時這一列灰掉；設了之後又拿掉，夜讀就不鎖了，免得打不開。從不鎖改成鎖之前先辨識一次，確定解得開才改。按了取消、失敗次數太多被系統暫時擋住、辨識出錯時都維持鎖住，畫面留一顆「解鎖」再叫一次。
- **鎖的畫面**：頁面底色，正中一個鎖的圖示，系統辨識框自動跳出；不放說明文字（ADR 0009）。解鎖後淡出（ADR 0022）。長什麼樣子由使用者在原型上選，寫進 `docs/design/screens.md`。
- **鎖住時底下不動**：底下的畫面不收點擊、不收返回鍵、不出鍵盤、讀屏軟體讀不到，動畫停住；音量鍵交回系統調音量，不翻頁。
- **開 App 的順序**：開著「解鎖才能打開」時，先出現鎖的畫面，解鎖後才播開 App 的進場（ADR 0025、0035）；沒開時進場照舊。
- **鎖住時照常的事**：朗讀與有聲書繼續播，通知欄、鎖定畫面的播放按鈕照樣能按；背景工作（ADR 0058）、同步、書架自動下載照常。通知欄與鎖定畫面照常顯示書名、封面與書源名，要不要藏交給手機系統的「鎖定畫面通知」設定。
- **從外面進來**：點書源檔、從別的 App 分享進來、點背景工作的通知，先解鎖，解鎖後才看到那一頁（匯入預覽、修復頁、搜尋頁）。
- **兩個設定是這台手機自己的**：不同步、不進備份，從備份還原時也不套用；另一台不一定有指紋。
- **權限**：Android 不跳詢問、「權限」頁不加列。iPhone 第一次解鎖時系統問能不能用 Face ID，「權限」頁多一列「Face ID」；拒絕了改用手機密碼解鎖。辨識由手機系統做，夜讀只知道過了沒有，不存、不送任何東西，寫進 `PRIVACY.md` 與 App 的「隱私說明」。

## 考慮過的做法

- **禁止截圖與錄影**：最徹底，但讀者不能截一段字分享、不能錄影回報問題；它在 Android 能做到的，蓋住畫面已經做到大半。不做。
- **Android 也畫模糊**：系統拍縮圖時夜讀的模糊常常還沒畫上去，看起來有時蓋、有時沒蓋。改成請系統不拍。
- **夜讀自己的密碼**：要做忘記密碼的出路，又多一組要記的東西；手機本身的辨識已經夠。不做。
- **「5 分鐘」靠背景計時**：手機可能在背景停住夜讀，計時不準，回來時也可能先閃一下內容才蓋上。改成每次離開都先蓋上、回來看時間。
- **進場在鎖的畫面底下照播**：解鎖時直接看到書架，但進場的動畫白播了。

## 觸點

| 觸點 | 答案 |
|---|---|
| 書源類型、校驗、AI 修書源 | 不適用 |
| 要登入、要網頁驗證 | 不適用：登入頁裡的瀏覽器在夜讀裡，不算離開；開外部瀏覽器登入的網址不算離開 |
| 付費章節 | 不適用 |
| 搜尋、發現、換源 | 不適用 |
| 手機上的檔案匯入 | 做：選檔案不算離開；從外面打開的檔案先解鎖 |
| 書架、書籍詳情、下載、清除、檢查新章節 | 照現狀：鎖住時書架自動下載照常 |
| 閱讀器、播放器失敗時的畫面 | 不適用 |
| 偏好、設定 | 做：「關於夜讀」的「隱私」兩列 |
| 進度、閱讀統計 | 照現狀：鎖住時不算在讀 |
| 書籤、標註、朗讀 | 照現狀：鎖住時朗讀繼續 |
| 通知、鎖定畫面 | 照現狀：照常顯示，交給系統設定 |
| 同步、備份 | 做：兩個設定不同步、不進備份、還原不套用；同步照常 |
| 匯出、和 Legado 互通 | 不適用 |
| `PRIVACY.md` 與「隱私說明」 | 做：加一段辨識由系統做 |
| `README.md`、網站 | 不做：小功能 |
| `GLOSSARY.md` | 做：加「解鎖才能打開」 |
| `docs/design/` | 做：`screens.md` 的「我的與設定頁」與鎖的畫面 |
| iPhone | 做：模糊由系統畫、Face ID；只有 CI 建置過，沒有實機跑過 |
| 自動巡檢 | 新檔案在 `lib/core/app_lock/`，照所在資料夾的分段 |
| 小說、漫畫、有聲、本地書 | 都一樣：整個 App 一起蓋、一起鎖 |

## 後果

- Android 夜讀的視窗改用另一種寫法，系統的辨識框才叫得出來（播放套件兩種都有提供），畫面與操作不變。
- 「離開就鎖」每次回來都要辨識一次；不想這麼頻繁的選「離開 5 分鐘後」。
- 多工畫面在 Android 上是空白的縮圖，不是模糊；Android 12 以下有的手機蓋不住。
