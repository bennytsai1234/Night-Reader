# 正文與介面字型可選，選了才下載

2026-10-30 使用者列「閱讀器寫死的地方改成可以調」時要字型可以選：內建幾套（思源宋體、霞鶩文楷）加系統字型，正文與 App 介面都能選，標點照樣由 `NightReaderPunct` 畫。2026-11-02 說明一套字型一個粗細就十幾 MB 後，使用者選「選了才下載」，不放進 App。這是第三批，也是這份清單的最後一批（第一批 #158、第二批 #215／#222，ADR 0043）。

## 決定

- **三種字型**（`AppFont`）：系統字型（預設，原本的樣子）、思源宋體、霞鶩文楷。正文在「閱讀偏好 → 排版 → 字型」，介面在「外觀與主題 → 介面字型」，各選各的；頁首頁尾跟著正文。兩個都跟著多台手機同步，正文字型跟著排版的「恢復預設」。
- **選了才下載**（`FontLibrary`）：檔案固定在某一版的網址（`raw.githubusercontent.com`，思源宋體是 noto-cjk `Serif2.003` 的繁中子集 7.9 MB，霞鶩文楷是 LxgwWenkaiTC `v1.530` 的標準粗細 15.3 MB），先寫成 `.part`，大小與 SHA-256 都對才改成正式檔名，對不上就丟掉、顯示「下載失敗」，再選一次重試。下載中選單列寫進度；還沒好時照舊用系統字型，好了正文重排、介面重建。
- **只下載標準粗細**：粗體（標題預設粗、正文可選粗）由排版引擎合成，省一半下載量。
- **開 App**：選了的字型已經下載過就在第一幀前註冊（`FontLibrary.start`），開 App 就是這套字；還沒下載的（例如另一台選的同步過來）在背景下載。只有選了下載字型的人多這一步。
- **字族順序**：字型清單是「第一套有這個字的勝出」。正文、頁首頁尾與量字格的地方分兩段排：中日文字（漢字、假名、注音、CJK 標點與全形字形）是「標點字型 → 下載的字型 → 平台預設 `sans-serif`」，其餘的字（英數字、西文標點、一般符號）是「標點字型 → `sans-serif` → 下載的字型」。英數字照舊用系統字型、照 ADR 0007 補半格；思源宋體自己的英數字吃了 `fwid` 會變成全形。原生 Android 的 `sans-serif` 只有 Roboto、沒有漢字，但不是每台手機都這樣：`sans-serif` 自帶漢字的手機，下載的字型排在它後面就輪不到，所以中日文字讓下載的字型先選（2026-11-13，審查時用實驗證實這個機制）。下載的字型沒有的字（子集外的罕見字）交給平台。
- 字族進排版的身分（`layoutSignature`、`StyleFingerprint.fontFamilySignature`、骨架紀錄的版面鍵、字格寬度的快取鍵），換字型整份重排。

## 推翻了什麼

- ADR 0030「選定即固定」與 `DESIGN.md` 設計原則第 6 條：字型是使用者點名要選的，例外寫在原則旁。
- `DESIGN.md` 否決過的「書名與標題改宋體（整個 App 統一用系統字型）」（2026-10-20）：那次否決的是由我們替整個 App 換掉字型；現在預設仍是系統字型，換不換由使用者自己選。

## 考慮過的做法

- **字型放進 App**：不用等下載，但 App 大 20 MB 以上，每次更新都要下載這麼大。使用者選了下載。
- **思源宋體用完整版**（24.5 MB）：子集收繁中常用字，小三分之二，罕見字由系統補上。
- **用手機自己的宋體（Android 的 `serif` 回退到 Noto Serif CJK）**：不用下載，但有沒有這套、長什麼樣看廠商，同一個選項在不同手機上不一樣。
- **連粗體一起下載**：大一倍，合成的粗體在閱讀字級上看得過去。
- **匯入自己的字型檔（Legado 的做法）**：ttc／otc 字型集合與字型檔的品質問題（Legado 使用者的 issue）都要處理；等使用者要再做。

## 沒做的（這份清單定下的）

- 每本書各自的設定：要使用者點頭才做。
- 維持不開放：翻頁方式（ADR 0006）、字格與避頭尾、滑動手感、選單動畫。
- 自動翻頁維持「每秒捲過螢幕高的 %」連續捲動，不加「每隔幾秒翻一屏」、不改成秒（2026-11-02）。
- 配色不再分字色、底色各自選：ADR 0040 的淺色、深色各選一個風格已經夠了（2026-11-02）。

## Consequences

- 下載走 `raw.githubusercontent.com`：連不上 GitHub 的網路下載不了，照舊用系統字型。
- 換字型的版本或來源時，連同 `AppFont` 的大小與 SHA-256 一起改，否則下載的檔案會被當成壞的丟掉。
- 介面字型只換照主題排字的地方；自己用 `TextPainter` 或 `ParagraphBuilder` 量字的少數元件（例如骨架量寬度）照舊是系統字型，寬度可能差一點。
