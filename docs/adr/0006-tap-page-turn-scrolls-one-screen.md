# 點擊翻頁就是捲動一屏，不做分頁模式

Reader V2 只有一份連續捲動的正文。點擊翻頁是把正文動畫捲動「視窗高度減一行」（`_movePageNow`），保留一行重疊，不對齊行界，也不切成固定的頁。2026-06-30 移除了另一套左右滑動的分頁模式（`0b85122`），從此正文只有一套座標，排版設定、跳章、朗讀跟隨與進度都不必在「頁」和「捲動位置」之間換算。連續快點時，每一下都接著前一下的目標繼續捲，不會把進行中的動畫直接跳到終點。

## Consequences

- 翻頁後畫面上下緣可能露出半行，這是刻意的；不要為了整頁對齊而改成分頁或吸附到行界。
- 不提供覆蓋、仿真等分頁翻頁動畫。
