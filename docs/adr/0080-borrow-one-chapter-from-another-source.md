# 單章借源：從別的書源只借一章的正文，蓋進主書源這一章

使用者 2026-11-23 要的：追連載時常常是主書源最快最穩，偏偏某一章是防盜章、少了一半或抓不到，為了那一章得把整本書換源。改成從別的書源只借這一章的正文存進本機，原本的書源與目錄不動。照 Legado 的「單章換源」做。

## 決定

- **借來的正文蓋進主書源這一章的位置，不記是借來的**（使用者 2026-11-23 選，同 Legado）。資料表不改。閱讀器照讀；書架自動下載當成已下載、不再抓；備份、匯出 TXT、書架匯出都把它當成這一章；同步本來就不帶正文，另一台讀到的還是主書源的那一章。
- **固定存著，跟著這本書已下載的正文一起留、一起刪**：重新取得本章（向主書源重抓、抓到才蓋掉）、清除已下載、換源、移出書架或沒加入書架就離開，以及主書源把這一章換了網址時，借來的就沒了。主書源修好了不會自動換回（夜讀分不出修好沒有）；要換回就按「重新取得本章」。
- **入口三個**：閱讀選單「更多」在「換源」後面的「單章借源」（借目前這一章；防盜章、半章都開得起來，不會走到失敗畫面）；開書失敗的按鈕列（借開不起來的那一章；還沒有目錄時灰掉）；跳章或捲到下一章取不到時提示旁的「借源」（取不到會退回原本那一章，「更多」借到的會是原本那一章；提示已經有「登入」「前往驗證」時那兩顆優先）。本地書的入口灰掉（ADR 0059）。
- **候選**：和換源面板同一套搜尋與清單（同一類加聚合源、回得快的在前、抓到目錄才列、寫「共 N 章」），頁首寫「單章借源」。選了書源後再核對書名、作者，抓完詳情要是小說。
- **章由使用者自己點**（照 Legado）：點書源打開它的目錄，捲到估計的那一章並標出來（先比章名、再比章號，同換源的對法），使用者點一章才借；分卷標題與付費章節不能點。借之前正文要「讀得到」（同換源）；讀得到不等於完整，半章、防盜章分不出來，借完使用者自己看。
- **怎麼抓、怎麼存**：用借的書源那本書與那一章抓，同一章分頁的停止點用借的書源目錄的下一章。存進主書源這一章的位置，主書源目錄的章名、字數不改（Legado 會改字數）。寫進去之前再看一次主書源這一章還在目錄裡、不是付費章節；關面板、離開閱讀器、再選一次都取消還沒寫進去的那次。插圖用借的書源抓；沒寫進去的那次（取消、這一章不在目錄、改成付費）把這次才抓下、已存的正文也沒用到的插圖刪掉；連不上的照現狀留給書架自動下載補（補的是主書源，多半補不到，那幾張不畫，ADR 0050）。
- **只有使用者明確的動作換得掉已存的正文**：借源與重新取得本章。閱讀器預載、書架自動下載、匯出補抓這類自動補抓只補還缺的章，晚到的結果不蓋掉已經存好的。
- **借的書源要登入或網頁驗證**：照 ADR 0038 在面板裡給「登入」「前往驗證」，開的是借的書源，回來重抓同一章。
- **借完**：借目前這一章時照目前的位置重排；開書失敗的照「重試」重開；跳章取不到的跳到那一章。畫面換好才提示「已從 書源名 借來本章」。書籤、標註照錨點找回同一句（ADR 0042、0044）；朗讀正在念這一章時先停；全書進度下次開書重算；書源膠囊照舊開主書源這一章的網頁。
- **只做小說**：漫畫的章是一包圖檔，要用借的書源的請求格式抓每張圖、打包，走另一條下載；有聲書的音訊網址多半有時效、不存成正文。

## 考慮過的做法

- **另外記「借自哪個書源」**：標得出借自哪裡、重新取得本章可以改向借的書源抓、插圖補得到，但要改資料表與備份格式；使用者選了不記。
- **章名對得上就自動借**：多半少點一下，但「番外」「感言」這類好幾章同名時會借錯、看不出來；借錯的一章悄悄存進去，不像換源換錯看得到。
- **借的書源要登入時只提示原因、請使用者換一個**：要在 ADR 0038 開例外；登入與驗證的頁面現成就有。

## 觸點

| 觸點 | 答案 |
|---|---|
| 書源類型、匯入時怎麼分 | 不適用 |
| 書源校驗怎麼判斷抓得到 | 只看「讀得到」，同換源；校驗的「只抓到第一頁」要抓那一章時的請求紀錄，借一章時不接 |
| AI 修書源 | 不適用：借源不改書源 |
| 要登入、要網頁驗證 | 照 ADR 0038：面板裡給借的書源的「登入」「前往驗證」 |
| 付費章節 | 照 ADR 0057：主書源的付費章節閱讀器本來就跳過，借不到；整本都是付費章節時開書失敗頁的入口灰掉；借的書源的付費章節點不了、抓的時候也擋。借的是別的書源的免費正文，不是購買 |
| 搜尋 | 不適用：用換源面板的搜法 |
| 發現 | 不適用 |
| 換源 | 做：和換源面板共用搜尋與清單；換源時借來的正文跟舊書源的一起刪 |
| 手機上的檔案匯入 | 不適用 |
| 書架 | 不做：書卡不加標記 |
| 書籍詳情 | 照現狀：已下載的章數、清除已下載、匯出都把借來的當成這一章 |
| 下載 | 做：自動補抓不蓋掉已存的正文；書架自動下載不碰借來的（ADR 0008） |
| 清除已下載、移出書架 | 照 ADR 0008：借來的一起刪 |
| 檢查新章節 | 照現狀：主書源把這一章換了網址時，借來的那筆對不上，從新網址重抓 |
| 閱讀器失敗時的畫面 | 做：開書失敗的按鈕列、跳章取不到的提示 |
| 偏好、設定 | 不做：沒有開關（ADR 0030） |
| 進度 | 照現狀：同步只帶第幾章第幾個字，兩台這一章長短不同時另一台會停在不同的句子 |
| 閱讀統計 | 照現狀：照書名、作者、類別記 |
| 書籤、標註、朗讀 | 照 ADR 0042、0044 的錨點；改得多時標註可能畫到別句；朗讀照正文改了的現狀先停 |
| 通知、鎖定畫面 | 不適用：在前景做 |
| 同步 | 不做：同步不帶正文，另一台要再借一次 |
| 備份與還原 | 照現狀帶；還原時備份裡那一版蓋掉這台的 |
| 匯出、和 Legado 互通 | 照現狀：匯出 TXT 與書架匯出含借來的；Legado 備份格式不受影響 |
| `PRIVACY.md` 與「隱私說明」 | 不改：只向使用者自己的書源送搜尋、目錄、正文與插圖的請求，同換源 |
| `README.md`、網站 | 不做：不新增宣傳項目 |
| `GLOSSARY.md` | 做：加「單章借源」 |
| `docs/design/` | 做：`reader.md` 的「更多」、失敗畫面與提示，`screens.md` 的借源面板 |
| iPhone | 照常：前景的操作，用同一套書源引擎 |
| 自動巡檢 | 做：新檔案排進所在資料夾的分段 |
| 小說、漫畫、有聲、本地書 | 小說做；漫畫、有聲不做（見上）；本地書不適用 |

## 後果

- 借來的正文和主書源的正文分不出來：閱讀器不標、之後也查不到借自哪裡。
- 借來的插圖連不上時，之後由主書源補，多半補不到，那幾張不畫；還原備份後也一樣。
- 另一台手機要自己再借一次。
