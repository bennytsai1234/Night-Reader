# 文字書的插圖：存的時候一律留下，顯示由「顯示插圖」決定，預設關

使用者 2026-11-09 要讓網路書正文裡的 `<img>` 與 EPUB 插圖夾在文字中間顯示，預設關閉。推翻 ADR 0032 的「插圖略過」；漫畫（整本都是圖的書源）另做一個閱讀器，不在這裡。

## 怎麼做

- **一個開關**：「閱讀偏好」的「顯示插圖」，所有書一起開關，預設關，放在繁簡轉換旁邊。它和繁簡轉換一樣是決定顯示哪些內容的開關，照 ADR 0030 放完整設定頁；插圖長什麼樣（大小、置中、間距）照設計原則第 6 條固定，不做成選項，Legado 的四種圖片樣式（`imageStyle`）不做。
- **存的時候一律留下，開關只管顯示**：網路書存正文時保留 `<img src="完整網址">`（`HtmlFormatter.formatKeepImg`，和 Legado 同格式），下載章節時一起把圖抓進這本書的資料夾；EPUB 轉文字時在插圖的位置寫同樣的標記，圖抽到同一個資料夾。開關關著也照樣抓、照樣抽，之後打開不用重抓或重轉。
- **關著時和沒有這個功能一樣**：讀正文時把標記拿掉，畫面、捲動位置、目錄都和這一版之前相同，不留「〔插圖〕」這類記號。
- **圖不算字**：位置、書籤、標註、本章進度都照字算，圖不佔字數，所以開關切換與舊的書籤、標註都不錯位。停在一張圖的中間離開，回來時到這張圖的頂端。
- **插圖一律獨立一塊**：段落中間的圖把段落切開。書源的 `imageStyle: TEXT`（把圖當一個字排在行內）也照插圖處理：查不到真的需要它的網站。整章由伺服器畫成圖的書源（例如飛盧的 VIP 章）不在這裡處理，書源校驗照舊判成讀不到字。
- **圖到了這章才算準備好**：排版前要知道每張圖多大，一章的圖都抓到或確定抓不到才排，期間紙蓋著；抓不到的圖當作不存在。版面一次到位，不先排字再補圖（設計原則第 1、3 條）。
- **確定抓不到才放棄，連不上下次再試**：網站回了錯誤碼、回的不是圖或解不出圖，記成確定抓不到，已存的正文再打開時不再抓，重新取得這一章才再試；連不上、逾時不記。已存的正文打開時，圖檔不在、也沒記成確定抓不到的圖先抓，抓完這章才算準備好。
- **插圖不進備份、不同步，算正文的一部分**：備份帶著已存的正文（裡面有圖的標記），但不帶圖檔。還原時，正文裡有插圖的網路書留一個「還沒抓圖」的記號，書架自動下載看到就排這本，只把已存正文裡還沒試過的圖抓下來、不換掉正文，都試過了就刪記號；連不上的那章算下載失敗，照 ADR 0008 的重試規則再試。同步不傳正文也不傳圖，另一台的書架自動下載抓正文時一起抓圖。插圖算進這本書的正文大小，和正文一起刪（移出書架、換源後舊來源的資料夾）。
- **EPUB 只有圖的章不列進目錄**（同 ADR 0032），圖併到下一章章名之後；章節清單不隨開關改變。封面頁那張圖已是封面，不放進正文。
- **舊資料**：EPUB 原檔一直保留著，App 更新後在背景重轉，讀者不用重新匯入。網路書已存的章在存的時候就刪了圖，看不出原本有沒有，所以不動；之後新抓的才有圖，要整本補就在書籍詳情清除正文，讓書架自動下載重抓（ADR 0008：正文只在使用者明確的動作中換掉）。

## Considered Options

- **每本書各自開**（Legado 的做法）：插圖要不要看是讀者對讀小說的整體偏好；每本有圖的書都得各開一次。
- **全域開關加每本書可以另外改**：同一件事兩個控制（ADR 0030 第 3 條）。
- **圖另存一份清單（章、字的位置、網址），正文維持純文字**：替換規則與重新分段會移動字的位置，清單對不上；兩份資料要一起改、刪、同步。
- **圖放共用的暫存資料夾、讀到才抓**：系統清掉後離線看不到，讀到時才知道多大，版面會跳。
- **開關關著時不抓圖**：之後打開，已下載的書還要整本重抓才有圖。
- **文字先排、圖先用固定比例的空位，到了再換**：圖和空位比例不同時下面的字會跳。
- **還原時不還原有圖的章**，讓書架自動下載整章重抓：書源失效或離線時連字都沒了。
- **每次開 App 掃整本正文找缺的圖**：開 App 時書架上每本書都要檢查要不要下載，每本都得把正文整份讀出來；只在還原時留記號。
- **抓不到的圖留「圖片載入失敗」框**：是解釋文字（ADR 0009），重試成功高度還是會變。
- **App 更新後書架上的網路書整本重抓**：對每個網站大量重抓，且沒經使用者同意就換掉存著的正文（ADR 0008）。
- **進度照捲動高度算**：同一個位置在不同螢幕是不同的百分比，同步與全書進度都要重做；照字算時捲過一張圖最多停一次翻頁。
- **點圖打開大圖**：圖佔滿一屏時點哪裡都是打開圖，不能點擊翻頁；改成長按看大圖。
- **深色時把圖調暗**：閱讀器已經有亮度條。

## Consequences

- 存著的網路書正文與 EPUB 轉出的文字裡會有 `<img>` 標記：替換規則、繁簡轉換、引號整理、匯出 TXT、書源校驗判斷「讀得到字」、轉檔時一章超過 5 萬字再切，都要先跳過或拿掉標記。
- 下載與書架自動下載多抓圖，佔空間、對網站的請求變多（圖片請求和章節一樣經過書源的限流）；圖不同步，另一台自己抓或自己轉。
- 還原備份後第一次開 App，書架上有插圖的網路書都會排一次下載，把圖抓回來；還沒抓到前打開那一章，紙會蓋著等圖。
- 書籍詳情「清除封面快取」不能再刪整個書本資料夾，要只刪封面。
