# 頁首一律置中小標題，不用大標題

所有頁首的標題都是 `GlassNavHeader` 工具列中間的置中小標題（18／w600），不用 iOS 那種頂端靠左的大字標題，也不做「大標題往下捲時收成小標題」的收合。2026-10-14 曾在書架與發現試過大標題（`b98c453`），使用者看過實機後要求移除：靠左大字和整個介面「置中、克制」的紙墨風格不合，頁首也因此變高。

## Consequences

- 新頁面與改版不要加回大標題、靠左的大字標題列或頁首收合；需要更醒目的標題時改內容區本身（例如書籍詳情的封面區），頁首仍是置中小標題。
- 頁首工具列沒有任何內容（沒有標題、按鈕，也不自動放返回鈕）時不留工具列的高度，只剩狀態列與下緣漸隱，例如「我的」分頁。
