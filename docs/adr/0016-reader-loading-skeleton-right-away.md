# 閱讀器載入時紙一蓋上就出骨架，頁首頁尾也一起畫成骨架

開書、跳到別章與重新排版時，正文區蓋上紙（`LoadingVeil`）的同一刻就開始淡入正文骨架，不設「等一段時間還沒好才出骨架」的門檻。開書與跳到別章時，頁首頁尾每個設定了的欄位也畫成骨架（照真正內容的寬度），正文排好後和正文一起換成真正的資訊。使用者的判斷是：實際使用時載入沒有快到一閃即過，延遲出骨架只會讓讀者多看一段空白的紙；整頁一起變成骨架、再一起換成內容，比部分先出現更一致。

## Considered Options

- **載入快時不出骨架**（等約 0.2 秒還沒好才浮出）：章節有快取時可以省掉骨架一閃，但載入通常沒那麼快，否決。
- **頁首頁尾只把進度畫成骨架**：時間、電量、書名、章名、章節序號在正文排好前就知道，可以照常顯示，只有本章／全書進度要等排版。使用者選擇整條資訊列一律畫成骨架，否決。
