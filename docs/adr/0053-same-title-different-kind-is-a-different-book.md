# 同名不同類是不同的書：書的類別照書源寫，認書的鍵加上類別，書跟著書源的類型改

使用者 2026-11-09 定：書名、作者都相同的小說、漫畫、有聲書算三本不同的書。搜尋時分成不同的卡，換源只列同一類的書源，書架同步、閱讀進度、書籤、標註、閱讀統計各記各的，三本可以同時在書架上。漫畫閱讀器（ADR 0052）與有聲書播放器（`feat/audiobook-player`）和本分支同一批合併，共用的部分在這裡定。

## 決定

- **書的類別只問一處**（`book.bookKind`，`SearchBook` 也有），回傳和書源同一組類別（ADR 0051 的小說、漫畫、有聲）。夜讀的書在 `type` 記書源類型（小說 0、有聲 1、漫畫 2），加入書架與換源時照書源寫；從 Legado 備份還原的書記的是 Legado 的位元（文字 8、有聲 32、圖片 64），兩種都認，認不出來的算小說。不另開一欄。
- **認書的鍵**：小說照舊用書名加作者，已存、已同步的資料不用搬；漫畫、有聲在書名前加類別前綴（`comic:`、`audio:`）。同步的書架與閱讀進度、閱讀統計、書籤、標註記的書名都帶前綴，點紀錄找書時書名與類別都要對上；搜尋合卡也照前綴分組。
- **換源只列同一類的書源**。
- **書源的類型改了，書架上用它的書跟著換類別**（使用者選的）：校驗、手動、同步、匯入存書源時一起改；改成夜讀不支援的類型時書不動。讀到第幾章留著；這本書在同步與閱讀統計裡換成另一類的那一筆，原本那一類的統計、書籤留在原處。換類別在書架同步裡等於換了鍵，沿用改名的機制送到另一台，另一台的書原地換類別，目錄與下載留著。
- **分得出是哪一類**：搜尋結果卡在漫畫、有聲書的封面左下角放圖示，閱讀統計放在書名後面（使用者在候選圖上選）。書架書卡不加，靠漫畫分支的預設封面變體（網點、音量條，`docs/design/components.md`「預設封面」）。

## 考慮過的做法

- **書籤、標註、閱讀統計各加一欄類別**：要改資料表，每日閱讀秒數的主鍵要重建；而書籤與標註只有文字閱讀器會寫。前綴放在書名裡，小說原本的資料一個字都不用動。
- **書源改了類型，書不動**：類型改成漫畫的書留在小說，文字閱讀器讀不了，也找不到能換的小說源。
- **書源改了類型先問使用者**：校驗是背景批次，跑完會跳一串確認。
- **搜尋卡在第二行前面寫類別、或書名旁加徽章**：使用者選了封面圖示。
- **書架書卡也放圖示**：使用者不要，交給預設封面變體。

## 後果

- 有真封面的書不會畫預設封面變體，書架上同名的小說與漫畫只靠封面不同來分；「統一封面」開著時才一眼分得出。
- 類型改錯的書源被改回來時，書會再換一次類別，兩次之間讀的統計分在兩邊。
