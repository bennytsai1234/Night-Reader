# 校驗連不上、網站不在了的書源建議移除；部分壞掉的留著交給 AI

使用者 2026-11-23 定：「任何不是校驗完整通過的，我都建議移除或是給 AI 修復」「都異常了」；部分壞掉的「先列為異常但不急著移除，只要其中幾個能用」。在這之前，上游異常、校驗超時與網站失效只隔離（排出搜尋與閱讀）、寫著「不視為永久失效」，不列入建議清理，書源管理畫成警示色、一直留在清單裡。

## 決定

| 校驗結果 | 處理 |
|---|---|
| 上游異常（連不上、回錯誤、擋下夜讀：要真人勾選、封鎖目前的網路、瀏覽器檢查沒過，含通過了重送還是被擋） | 隔離，建議移除；照樣交給 AI 修，修好就拿掉 |
| 校驗超時 | 同上 |
| 網站失效 | 隔離，建議移除 |
| 網站不穩定、付費、只能下載、影視與文件類 | 建議移除（照舊） |
| 搜尋、詳情、目錄、正文、發現失效 | 標異常、交給 AI 修；修不好也不建議移除（照舊） |
| 需要登入、需要在網頁驗證 | 是狀態，不是壞掉，照樣能用（照舊，ADR 0038）；不要的用「按標籤刪除」 |
| 已隔離（校驗跑到一半意外出錯，沒判出是哪一種） | 隔離，建議移除；照樣交給 AI 修，修好就拿掉（使用者 2026-11-23：原本當成不是書源的問題、不建議移除，AI 修不好就一直留著） |

建議移除只是標記：書源管理畫成危險色、校驗結果算進「建議清理」，用「按標籤刪除」或修復異常書源的結果頁刪，不自動刪。書架上的書的書源被刪掉時照 ADR 0069 自動換源。

## 推翻了什麼

- ADR 0033：要真人勾選、封鎖網路時「那個書源當成暫時不能用，書源校驗把它隔離」，現在隔離之外也建議移除。在公司網路被擋、換網路能用的書源一樣會建議移除，使用者接受。

## 考慮過的做法

- **瀏覽器檢查通過了、重送還是被擋時，改用看不到的瀏覽器開頁抓**：每次搜尋、每一章都要等網頁跑完，整本下載很慢。使用者：「太慢了」「直接列為移除」。
- **把「通過了還被擋」拆成另一種錯誤、單獨建議移除**：上游異常整類都建議移除後不必分。
- **AI 修不好的一律建議移除**：部分壞掉的書源還有能用的部分（例如發現頁壞了照樣能搜能讀），使用者要留著。
