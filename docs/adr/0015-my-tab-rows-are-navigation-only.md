# 「我的」分頁只放入口，不放開關

「我的」分頁第一層的每一列都是進入下一頁的入口（圖示、標題、右側箭頭），排列一致，不放開關或其他能直接改值的列。設定開關放到它所屬的二層頁面裡。2026-10-14 使用者要求把原本夾在「書源管理」「背景下載佇列」「資料與隱私」之間的「啟動時檢查書架更新」移到「關於夜讀 → 系統工具」，第一層就不再有開關。

## Consequences

- 新增設定時先找它所屬的二層頁面；找不到合適的頁面時，寧可在二層頁新增一組，也不把開關放回第一層。
- 「啟動時檢查書架更新」放在「關於夜讀 → 系統工具」，和 App 的更新設定放在一起。
- 2026-10-20 使用者說選項多到控制不完、分級看不懂，「資料與隱私」整頁併進「關於夜讀」：隱私說明與「權限」（權限狀態加說明）放在「開源與法律」，原本三個分開的清除按鈕合成「系統工具 → 清除網頁資料」。第一層少一列；之後新增的設定一樣先找現有的二層頁面，不另開一頁。
