# 封面只畫圖片，不做成像一本書

`BookCoverWidget` 只畫封面圖片本身（圓角 `AppRadius.cardXs` 與底下的陰影保留），不在圖片上疊任何仿實體書的效果：左側書脊的暗邊與摺痕漸層、靠左 3 的白色亮線、右緣書頁陰影、白色髮絲框都拿掉。2026-10-16 使用者指出封面左半部有一條線，要求移除：只要圖片，不要真的像一本書。

這些效果是 `f0c7d5e`（「tactile book spine lighting」）加的，當時 DESIGN.md 寫「搭配左側書脊裝訂微陰影，呈現實體書厚度感」，沒有使用者要求的紀錄。

## Consequences

- 書架、搜尋、發現、書籍詳情等所有用 `BookCoverWidget` 的地方一起變；預設封面「夜空」（`DefaultBookCover`）也不再被疊書脊。
- 之後調封面樣式時，不加書脊、書頁厚度、裝訂陰影這類擬物效果。
