# 每本書可以反轉目錄，存著的目錄整個翻過來

有些書源給的目錄是新到舊。書的閱讀設定裡本來就有 `reverseToc` 這一格（Legado 的「反轉目錄」，從 Legado 匯入的書會帶著），夜讀抓目錄時也照它翻，但 App 裡從來沒有開關；書籍詳情目錄的「倒序」只改顯示，閱讀時的上一章、下一章仍是反的。對照 Legado 閱讀的 T3，使用者 2026-11-25 勾選。

## 決定

- 閱讀器「更多」一個「反轉目錄」開關，接在「重新分段」後面，打開時打勾，預設關（同 Legado 放在目錄頁的選單，`TocViewModel.reverseToc`）。點了把這本書存著的目錄整個翻過來、重新編號，之後抓的也照翻，閱讀器照翻過來的目錄重開、停在同一個位置（同「設定編碼」）。
- **存著的目錄永遠等於「書源給的順序，開著時再翻過來」**：開關只從一個地方改（`BookTocReverser`），存著的目錄跟著一起翻。會換掉目錄的地方都照這個：
  - 檢查新章節照開關抓；抓的途中切了開關，抓到的照現在的開關再翻一次。
  - 換源、自動換源帶著這本書的閱讀設定（同 Legado `Book.migrateTo`），新書源的目錄照開關翻好才對讀到的那一章。
  - 另一台切了開關，同步到這台時這台存著的目錄一起翻。
- **跟著同一章**：閱讀進度照章節網址對回同一章，章內位置與錨點不變；已下載的正文照章節網址存，不用動；指定範圍的下載記的是起訖兩章，翻過來照樣下載這兩章之間。還照舊目錄開著的閱讀器存進度時照章節網址對到新目錄。
- **書籤與標註記下序號照的方向，序號不動**：每個書籤、標註記著留下時目錄有沒有翻（`tocReversed`；舊版與 Legado 的沒記，當成和這本書現在一樣）。翻目錄時只把沒記的記成翻之前的方向，已經記了的不動，所以同名同作者好幾個書源共用的書籤，翻哪一本、翻幾本都只記一次。用的時候照 ADR 0042 先比章名，同名的章（例如兩個「番外」）才看序號：記下的方向和這本書現在不同，序號從這台目錄的另一頭數。換源時照舊書的方向換成舊目錄的序號再對新目錄，記下新書的方向。
- **同步帶著方向**：書籤、標註記了方向就算進同步的內容，記下方向時一定送出；閱讀進度的紀錄帶著目錄方向，反轉了的算進內容，另一台的方向和這台不同時先從另一頭數再找同名的章，所以日常的進度同步比書架上的開關先到也對得到同一章。
- **本地書灰掉**：目錄照檔案的順序；EPUB 對檔案時會照檔案重轉目錄。

## 觸點

| 觸點 | 答案 |
|---|---|
| 書源類型、校驗、AI 修書源、付費章節 | 不適用：只動這本書存著的目錄；付費章節的鎖頭跟著章走 |
| 要登入、要網頁驗證 | 不適用：翻目錄不連網 |
| 搜尋、發現 | 不適用 |
| 換源 | 做：帶著開關（同 Legado），新書源的目錄照開關翻好；自動換源同一套 |
| 手機上的檔案匯入 | 不做：本地書灰掉 |
| 書架、書籍詳情 | 書籍詳情的目錄照存著的順序；詳情的「倒序」照舊只改顯示 |
| 下載、清除已下載 | 正文照網址存不動；指定範圍照起訖兩章之間 |
| 檢查新章節 | 照開關抓；途中切了照現在的開關翻 |
| 閱讀器、偏好放哪 | 每本書的開關，閱讀器「更多」（同重新分段，ADR 0030 邊讀邊會調的放閱讀器），預設關 |
| 進度、書籤、標註、朗讀 | 跟著同一章；上一章、下一章、朗讀換章照新的順序 |
| 閱讀統計、通知 | 不適用 |
| 同步 | 做：開關在書的閱讀設定裡，跟著書架同步；另一台收到時翻自己存著的目錄；進度、書籤、標註帶著序號照的方向 |
| 備份與還原、和 Legado 互通 | 備份不帶目錄，還原後照開關抓；欄位就是 Legado 的 `reverseToc` |
| `PRIVACY.md` 與「隱私說明」、`README.md`、網站、`GLOSSARY.md` | 不改：不多送資料，是既有閱讀設定的開關 |
| `docs/design/` | 做：`reader.md`「閱讀器選單」 |
| iPhone | 一樣 |
| 自動巡檢 | 不適用：沒有新的資料夾與服務 |
| 小說、漫畫、有聲、本地書 | 只在文字閱讀器有開關；漫畫、有聲書沒有入口，同步帶來的開關照樣翻存著的目錄；本地書灰掉 |

## 考慮過的做法

- **照 Legado，只翻目錄、不動閱讀進度**：Legado 翻完目錄把讀到第幾章的序號原樣留著，翻過來就指到另一章；書籤也一樣。夜讀照章節網址對回同一章。
- **換源時關掉開關**：開關是給「這個書源的目錄新到舊」的，換到正常的書源反而變成反的；但 Legado 換源帶著整份閱讀設定，照 Legado。換過去反了再點一次就好。

## 後果

- 和 Legado 刻意不同：翻目錄時進度、書籤、標註跟著同一章（Legado 不跟）；換源時新書源的目錄當下就照開關翻（Legado 要等下次更新目錄）。
- 下載管理的「查看失敗原因」寫的「第 N 章」是失敗當時的序號，翻過來不改。
- 翻目錄會重開閱讀器，照換頁動畫進來。
- 從另一頭數照的是這台這本書的章數：同名同作者的另一個書源章數不同、或原本的順序不同時，數出來的序號只是估的，再靠章名對；只有同名的章可能對到另一個。
