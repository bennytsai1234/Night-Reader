# 介面語言：繁體中文、簡體中文、跟隨系統

使用者 2026-11-15 要讓整個 App 的頁面與設定支援繁簡切換，並自行挑選語言。

## 決定

- 「我的 → 外觀與主題 → 介面語言」以一列設定開選單，提供「跟隨系統」「繁體中文」「简体中文」，預設跟隨系統。
- 系統中文為簡體語系（zh-Hans、zh-CN、zh-SG、zh-MY）時顯示簡體，繁體語系（zh-Hant、zh-TW、zh-HK、zh-MO）顯示繁體；非中文系統保留繁體。使用者明確選擇的結果優先。
- 介面文字以現有繁體字串為來源，使用 App 已載入的 OpenCC 詞組與單字表轉成簡體；不複製第二份選單、標題、狀態或錯誤文案。新介面元件必須經過同一套顯示轉換。
- 頁首、底部導覽、選單、提示框、空頁、錯誤、操作狀態、設定頁、文字按鈕以及有聲書與漫畫操作介面都在範圍內；使用者輸入、原始網址、JSON、書源規則與資料庫儲存值一律不轉換。
- **介面語言與閱讀偏好的「繁簡轉換」各自獨立**：介面可以是簡體，書籍正文仍照使用者選擇顯示繁體（反之亦然）。資料庫存的書名、正文與搜尋關鍵字原文不變，繁簡搜尋照原本的做法。
- 介面語言記在現有 language 偏好鍵，讀取舊值 system、zh_TW、zh_CN；後續變更即時更新畫面。介面語言是裝置自己的偏好，不進跨裝置同步（跟裝置語言判斷一致）。

## 範圍與代價

- 轉換只解決繁簡字形與詞組，不宣稱完成中國大陸用語的在地化；需要特殊用詞時再以少量明確覆寫處理。
- 版型與操作流程保持原樣，不加教學頁、不加搜尋引導、不改閱讀器臺灣標點規格。
- 必須檢查元件實際顯示的文字、溢位文字量測，以及無障礙與輸入提示，不能只改頁面標題。
