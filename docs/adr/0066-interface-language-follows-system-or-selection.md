# 介面語言：繁體中文、簡體中文、跟隨系統

使用者 2026-11-15 要讓整個 App 的頁面與設定支援繁簡切換，並自行挑選語言。

## 決定

- 「我的 → 外觀與主題 → 介面語言」以一列設定開選單，提供「跟隨系統」「繁體中文」「简体中文」，預設跟隨系統。
- 系統中文為簡體語系（zh-Hans、zh-CN、zh-SG、zh-MY）時顯示簡體，繁體語系（zh-Hant、zh-TW、zh-HK、zh-MO）顯示繁體；非中文系統保留繁體。使用者明確選擇的結果優先。跟隨系統時，App 開著改系統語言也馬上換：`UiLanguageScope` 自己聽系統語言的變更（App 沒有宣告中文語系，Flutter 把繁體、簡體都解析成預設的英文，`MaterialApp` 不會因為系統改繁簡而重建）。
- 介面文字以現有繁體字串為來源，使用 App 已載入的 OpenCC 詞組與單字表轉成簡體；不複製第二份選單、標題、狀態或錯誤文案。介面文字一律用 `UiText`，共用元件（分組列、選單、膠囊鈕、頁首、對話框、輸入框）收到的字串由元件自己轉。
- 頁首、底部導覽、選單、提示框、空頁、錯誤、操作狀態、設定頁、文字按鈕、工具提示與讀屏名稱，以及有聲書與漫畫操作介面都在範圍內。
- **介面語言與閱讀偏好的「繁簡轉換」各自獨立**：書的資料（書名、作者、章名、卷名、分類、簡介、書籤摘錄、標註）照閱讀偏好的繁簡轉換（`context.zh`），使用者與書源寫的字（搜尋紀錄、AI 找書的描述、備忘、替換規則與它跑出來的測試結果、書源名稱、網址、分組、發現分類、登入表單、書源程式給的訊息）照原文。顯示這些資料的地方給 `translate: false`（共用元件是 `translateTitle`、`translateSubtitle`、`translateValue`、`translateHeader`、`translateMessage`、`translate` 這組參數）；資料和介面字並排成一段時（「最新：章名」、字數單位、「登入 · 書源名稱」這類頁首），介面字用 `context.ui`、資料用 `context.zh` 或原文，整段 `translate: false`。資料庫存的書名、正文與搜尋關鍵字原文不變，繁簡搜尋照原本的做法。
- **句子裡夾著的名稱跟著句子**：提示列、確認框的說明、錯誤訊息這類 App 組好的句子（「確定刪除「書源名稱」？」「還在等：書源 A、書源 B」），整句照介面語言轉，裡面的書名、書源名稱也一起轉。這些句子傳到顯示的地方時已經是一整段字，又只是一閃而過的提示；整段都是資料的（對話框標題是書源名稱、說明是網址或書源給的訊息）才照上一條保留。
- 背景工作的通知（標題、內文、「暫停」「結束」按鈕）照介面語言整段轉換，內文裡的書源名稱也跟著轉：通知由同一個出口送到系統，那裡分不出哪段是資料。通知頻道的名稱（系統設定裡的「背景工作」）照舊繁體。有聲書與朗讀送給系統的播放資訊（通知欄、鎖定畫面、藍牙）是書名與章名原文，不照閱讀偏好轉。
- 介面語言記在現有 language 偏好鍵，讀取舊值 system、zh_TW、zh_CN；後續變更即時更新畫面。介面語言是裝置自己的偏好，不進跨裝置同步（跟裝置語言判斷一致）；備份照樣帶著（備份帶所有偏好設定）。

## 範圍與代價

- 轉換只解決繁簡字形與詞組，不宣稱完成中國大陸用語的在地化；需要特殊用詞時再以少量明確覆寫處理。
- 版型與操作流程保持原樣，不加教學頁、不加搜尋引導、不改閱讀器臺灣標點規格。
- 介面是繁體時不轉換，也不多登記任何重建；介面是簡體時，字典載入完成後顯示介面文字的地方重建一次（開 App 的進場等字典載完才開始，ADR 0035）。
- 書的資料漏標 `translate: false` 時，介面選簡體會把它轉成簡體、蓋掉閱讀偏好；`test/core/services/ui_language_book_data_test.dart` 在書籤、目錄、下載佇列、對話框、替換規則的測試結果上守這條，也守跟隨系統時改系統語言。

## 觸點

照 `docs/agents/new-feature.md` 走過一遍。

| 觸點 | 答案 |
|---|---|
| 書源類型、校驗、AI 修書源、登入、付費章節 | 做：介面字轉換；書源的名稱、分組、登入表單、書源程式給的訊息照原文；App 組的錯誤句子照介面語言 |
| 搜尋、發現、換源 | 做：介面字轉換；書名、作者、最新章名照閱讀偏好，書源名稱與分組照原文；搜尋比對不變 |
| 手機上的檔案匯入 | 做：匯入流程的介面字轉換，本地書的書名照閱讀偏好 |
| 書架、書籍詳情、下載、清除、檢查新章節 | 做：介面字轉換；書卡、詳情頁首、目錄、下載佇列的書名與章名照閱讀偏好 |
| 閱讀器、播放器、漫畫閱讀器 | 做：選單、面板與讀屏名稱的介面字轉換；正文、頁首頁尾的章名、換章分隔的章名、有聲書頁的書名與集名照閱讀偏好 |
| 偏好放哪一頁 | 外觀與主題，玻璃效果下面一列（ADR 0030） |
| 進度、閱讀統計、書籤、標註、朗讀 | 做：介面字轉換；書名、摘錄、章名照閱讀偏好，備忘照原文 |
| 通知、鎖定畫面 | 背景工作的通知照介面語言；系統播放資訊是書名章名原文 |
| 同步、備份 | 不同步、備份帶著（見上） |
| 匯出、和 Legado 互通 | 不適用：匯出的是書的內容 |
| `PRIVACY.md` 與隱私說明 | 不適用：不多收、不多送資料；隱私說明的頁面字照介面語言 |
| README、網站 | 不做：照舊只寫繁體 |
| `docs/design/` | `appearance.md`「介面語言」 |
| iPhone | 做：同一套 Dart 程式；iPhone 沒有背景工作的通知 |
| 小說、漫畫、有聲書、本地書 | 四類一樣：介面字照介面語言，書的資料照閱讀偏好 |
| 自動巡檢 | 不用排新的段：沒有新的資料夾或服務 |
