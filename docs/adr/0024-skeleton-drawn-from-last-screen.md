# 骨架照上次的畫面畫，骨架換場的方式可選

骨架照樣出現，但形狀照上次看到的真實畫面畫，而不是固定的樣式：書架記下本數與前 30 本的書名、作者，骨架的書名長條照真正書名的換行與寬度畫；閱讀器在離開或 App 切到背景時記下畫面上每一行字的位置與當時的進度，下次從同一處、用同樣的版面開這本書時，紙上的骨架照那一頁畫，頁尾進度欄的骨架照當時的字樣量寬。骨架換場時每一條長條剛好換成那一行字，不會有對不上的收尾跳變。骨架換成內容的方式在「外觀與主題 → 骨架換場」選：由左而右（預設）或整頁淡入，時長 0.2–1.5 秒可調、預設 0.6 秒。使用者的判斷是（2026-10-17）：要的是骨架之後的換場自然，不是省掉骨架；在原型上比過整頁淡入與由左而右後，選由左而右當預設，其他方式留給個人喜好。

紀錄存在偏好設定：開 App 時已整份讀進記憶體，開書時同步取得，換頁動畫播放中不碰磁碟（ADR 0018）。對不上（跳章、改了排版、換了位置、沒有紀錄）時照原本的固定樣式畫。

## Considered Options

- **整個書架記下來、開 App 直接畫出書**：封面仍要解碼，只能再閃一下骨架或讓系統啟動畫面多停，好處只有少等一點（ADR 0023），否決。
- **書一本一本依序淡入**：ADR 0017 要的是書與封面一起出現，看起來也比較碎，否決。
- **由左而右加一道柔邊光帶掃過**：使用者覺得多餘，只要左邊先出、右邊後出。
- **用版面的 `presentationSignature` 判斷版面是否相同**：它是 `Object.hash`，每次啟動 App 的雜湊種子不同，存起來下次比不上；改成把決定行位置的版面參數逐項寫成字串。

## Consequences

- 換場時長從原本的 0.25 秒（閱讀器）與 0.4 秒（書架）一律改成使用者的設定，預設 0.6 秒。
- 第一次開新版、或讀一本十本以前讀過的書時沒有紀錄，照固定樣式畫一次。
- 閱讀器記下的進度在開書時先放進進度通道，排好後換成重算的同一個進度。
