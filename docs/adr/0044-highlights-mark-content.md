# 標註記內容，跟著書走的方式和書籤同一套

使用者 2026-11-01 定要做標註：把一段字畫上底色或底線（可選顏色），在清單裡看所有畫過的段落，能匯出。書籤記位置，標註記內容。

## 怎麼做

- **一個標註記**：書名、作者、章名與這台目錄裡的章節序號、開頭是章內第幾個字、開頭那個字綁定的正文錨點（同書籤，ADR 0042），畫到的那段字本身、顏色（黃、綠、藍、粉、紫）與樣子（底色、底線）。清單與匯出照記下的字，不再回去讀正文。
- **畫在哪裡**：開頭照錨點找回（正文變了照前後原文），往後畫記下的那麼長；只在一段裡（選字本來就不跨段）。底色和朗讀高亮同一套，貼著字形鋪、上下以行格為界；底線畫在每一行字的下緣。每個標註記住自己在文件上的行框，捲動時每一幀只扣捲動位置（同書籤的記號）。
- **怎麼畫**：選字選單「⋮」裡的「標註」，按下就畫，顏色與樣子沿用最近畫的一個（第一次黃色底色），提示可「復原」，不先開面板。「⋮」原本只收系統能處理文字的 App，現在手機上沒有那類 App 也會顯示（列上已經是複製、搜尋、隱藏、書籤，之後還有替換）。
- **備忘**：標註旁附的一段自己的話，不放選字選單，點已畫的標註在面板裡寫（使用者 2026-11-01 定）。面板收起或切到別的 App 時存一次（在背景被系統結束也不會丟），不是每打一個字存；刪除時不再存回去，復原時連備忘一起回來。清單在章名下面多兩行顯示，匯出時接在那段引用下面。schema 12 加這一欄，同步時算內容。
- **點已畫的標註**：打開標註面板，換顏色、換底色或底線（換了就存）、寫備忘、複製、刪除。點到的字落在標註裡才算，其餘照常翻頁、叫選單。
- **清單**：閱讀器目錄面板多一個「標註」分頁，「我的 → 書籤與標註」頂端分「書籤｜標註」兩頁；都照在書裡的先後排，列首一條標註的顏色，往左滑刪除可「復原」。
- **匯出**：Markdown 檔（一本書一個標題、章名分段、每個標註一段引用），從系統分享選單存或傳。目錄面板匯出這本書的，「我的」匯出所有書的。
- **跟著書名加作者、編號、換源、同步、備份**：全部照書籤（ADR 0042）：編號用 `BookmarkDao.newId` 的配法；換源在 `commitSwitch` 的交易裡跟著搬到新目錄的同一章；同步一個標註一筆、刪除也同步，章節序號與錨點不算內容，顏色與樣子算；表一改隔 5 秒同步；備份 `highlight.json`。

## Considered Options

- **記開頭與結尾兩個錨點**：結尾照長度推就夠，正文只差標點、繁簡時長度不變；兩個錨點各自找，找到的結尾可能在開頭前面。
- **選取後先開面板挑顏色**：多一步；多數時候沿用同一個顏色，要換再點標註。
- **重疊時合併成一個**：兩段畫成不同顏色時合併就丟了一個顏色；重疊照畫，點到時開最後畫的那個。
- **匯出成 TXT**：Markdown 一樣是純文字、照樣讀得懂，貼到筆記 App 還有標題與引用的層次。

## Consequences

- schema 11 新增 `highlights` 表，schema 12 加備忘；同步空間多一份 `highlights.json`。
- 「⋮」一定會顯示（只要有標註），選單比以前多一顆按鈕的寬。
