# 每本書可以打開「重新分段」，照 Legado 重排正文

網站給的正文有時亂換行：句子中間斷行、沒有標點可看（「他推開門走了」換行「進去，」），或整章擠成一行。自動修（ADR 0073）只接有排版證據的換行，這種分不出是斷行還是本來就短的一段（「三天後」、狀聲詞、系統面板、詩），不接。書的設定裡本來就有 `reSegment` 這一格（從 Legado 匯入的書會帶著），但 App 裡從來沒有開關，開著時也只切整章一行的。使用者 2026-11-23 定案。

## 決定

- 每本書一個「重新分段」開關，存進書的 `reSegment`，預設關；閱讀器右上角「更多」（打開時打勾，同 Legado 放在閱讀選單）與替換規則面板（「本書套用替換規則」下一列）都有，使用者 2026-11-23 看過候選圖兩處都要；打開或關掉後重新載入正文，和「本書套用替換規則」一樣。設定跟著書同步、備份，欄位和 Legado 互通。本地書（TXT、EPUB）也有；漫畫、有聲書沒有正文，不適用。
- 打開後照 Legado 的 `ContentHelp.reSegment`（`ContentReSegmenter`）：不以句末標點收尾的行接到下一行，跨過空白行；再照對白切段（引號連著引號、「說道。」之後、冒號引號開始的發言），列舉（“鍋”、“碗”）不切，長段照句子數拆開，修正引號方向、補上缺的收引號。位置和 Legado 一樣在去重複章名之後、替換規則與繁簡轉換之前；選字「隱藏」用的原文走同一段。
- 原本「整章一行、超過 180 字時一句切一段」的做法刪掉，整章一行也照上面重排。
- 和 Legado 刻意不同的：
  - **長段拆不拆用固定亂數**：Legado 用 `Math.random()`，同一章每次開段落都不同，書籤、標註、進度會跑掉。夜讀用這一段的字算 FNV-1a 雜湊當種子（不用 `String.hashCode`，它不保證各版本、各平台一樣），機率照 Legado，同一章每次、每台手機都一樣。
  - **英文空格留著**：Legado 刪掉段內所有空白。夜讀照刪，兩邊都是英數字的空白留一個（連續的縮成一個）；接起來的兩行兩邊都是英數字時補一個空格；上一行以連字號結尾時連字號留著、直接接（分不出複合詞與斷字，刪了會把 well-known 接成 wellknown）。
  - **只有插圖的行是邊界**：兩張插圖之間各自重排，圖不會被併進字裡（ADR 0050）。
  - **先跑一次自動修**：行首落單的收引號（「請進。」換行「」一個聲音傳來。」），Legado 會把下一行當成新的對白、補成一整對引號；先照 ADR 0073 接回再重排。
  - **認「」與繁體**：Legado 只認 “” 與簡體的說話字（说、道、着…）、列舉連接詞（和、与、或）。夜讀「」當 “” 處理，原文只用「」時重排完換回「」；說話字與連接詞補上繁體。繁簡轉換在最後，這一步看到的是網站原文。

## 考慮過的做法

- **預設打開，或全域預設**：Legado 沒有全域預設，只有閱讀選單的開關。預設打開會讓每本書都被改段：停在「……」「——」或沒有標點的行接到下一行、對白重新切，ADR 0073 否決的就是這個；升級那次所有書的書籤與標註位置都要重新對。全域預設要把 `reSegment` 改成可以是「沒設過」，匯出給 Legado 時它讀到空值會出錯；只在加入書架時寫進書又改不到已在書架上的書。亂換行是網站的問題，讀者遇到一本開一本。
- **空白行仍是邊界**（ADR 0073 原本的說法）：有的網站每一行後面都空一行，開了也接不回。空白行本來就不顯示（排版時空段落拿掉），跨過去後網站段落之間有沒有空一行，結果都一樣。

## 後果

- 打開或關掉時，這本書的書籤、標註與閱讀位置照新的正文對，和新增一條替換規則時一樣；記在被改動的字旁邊的位置可能偏到前一段。
- 從 Legado 匯入、本來就開著的書，升級後分段變一次（原本只切整章一行的）。
- 排得好好的書打開後也會被改段（停在「……」的行接到下一行、長段被拆開），所以預設關、每本書各自開。
- 重排在內容轉換 worker 裡跑，不佔畫面執行緒。
