# 設定的分級與全部選項的去留

使用者說（2026-10-20）可以控制的選項多到控制不完，選單與設定的分級也看不懂，交給 agent 自主盤點、收掉。這份是盤點的結果：所有使用者看得到的設定放在哪裡、每一項留下或拿掉的理由，以及之後新增設定時照的分級規則。

## 分級規則

1. **邊讀邊會調的，放在閱讀器裡的面板**：只放讀到一半會想改、改了馬上看得到的項目（字號、行高、段距、左右邊距、風格；朗讀的語速、定時、高亮）。
2. **設一次就不太動的，放在一個完整的設定頁**：閱讀相關的全在「閱讀偏好」，朗讀聲音在「朗讀與語音」，外觀在「外觀與主題」，App 本身在「關於夜讀」。閱讀器的「進階」與面板的「更多排版設定」都直接推入「閱讀偏好」，不另開一個內容相同的面板；完整頁蓋著閱讀器時閱讀器不排版，關掉後才重讀設定（ADR 0018）。
3. **同一件事只留一個控制**：兩個開關其中一個只在另一個開著時有用，合成一列三選一；系統已經有的控制（媒體音量）不再做一份；結果相同的幾個動作（清 Cookie、localStorage、快取）合成一個。
4. **「我的」第一層只放入口**（ADR 0015），一個入口一頁（「檢查更新」是例外，點了就檢查），九個（使用者 2026-10-23：十個有點太多，九個剛好）；新設定先找現有的頁面，不另開一頁。
5. **一列裡的選項（例如強調色的幾種顏色）不算控制項**：使用者說的「控制不完」是要操心的項目太多，選項多的那一列仍只是一列；只合併真的重複的選項。

## 全部選項與去留（2026-10-20 之後）

### 我的（第一層，9 個入口）

閱讀偏好、外觀與主題、朗讀與語音、閱讀統計；書源管理、背景下載佇列、備份與還原、檢查更新、關於夜讀。「資料與隱私」併進關於夜讀（#89）。檢查更新是使用者 2026-10-21 選的，從關於夜讀移過來，不留兩個入口；崩潰日誌當時一起移出來，2026-10-23 使用者覺得十個太多，移回關於夜讀的「系統工具」。九列在一般高度的螢幕一頁放得下（頁底只留 14 的空白）；更矮的手機（例如 16:9 的舊機型）照常捲動，不把列壓到 44 以下，那會難點。

### 外觀與主題

| 項目 | 去留 |
|---|---|
| 淺色風格、深色風格（各 6 種）、深色用純黑、強調色（跟隨主題＋12 色） | 留。風格淺色、深色各一排，純黑是深色那區的一列開關（ADR 0040）。2026-10-20 精簡成五種，2026-10-24 使用者要求把胭脂、藕荷、黃卷、琥珀、霜夜加回來，2026-11-01 量過後精簡成六種並加入 Legado 的豆綠、牛皮紙 |
| 深淺（跟隨系統／淺色／深色） | 留 |
| 玻璃效果（實色、霧面、通透、玻璃） | 留。一列分段選擇，四段看起來差別明顯 |
| 換頁動畫 | 留 7 種（上浮、平移、滑入、推進、覆蓋、縮放、展開）；「俐落平移」拿掉，它和平移只差在曲線，選了它的回到平移 |
| 骨架深淺、骨架呼吸、骨架換場、換場時長 | 拿掉（#85），固定用使用者在原型上選的值 |

### 閱讀偏好（完整頁）

排版（字號、標題字號、行高、字距、段距、章節間距、首行縮排、恢復預設）、版面（左右邊距、左右對齊、上邊距、下邊距、頁尾位置、恢復預設）、隱藏系統狀態列、頁首與頁尾（左右各一欄）、自動翻頁速度、繁簡轉換、點擊區域（九格）、音量鍵翻頁：全部留，這裡是閱讀設定唯一的完整位置。

### 閱讀器裡

| 位置 | 內容 |
|---|---|
| 外觀與排版面板 | 風格、字號、行高、段距、左右邊距、「更多排版設定」→ 閱讀偏好（#91） |
| 下方選單「進階」 | 推入閱讀偏好；原本內容相同的「進階設定」面板拿掉 |
| 朗讀面板 | 語速、朗讀高亮的顏色（跟隨主題＋5 色，一列）與深淺、定時：高亮要對著正文看才調得準，所以留在閱讀器；「音調」拿掉，只在朗讀與語音（挑聲音時才調） |
| 選單按鈕 | 亮度條、日夜切換、自動翻頁、替換規則、定時朗讀：留，都是動作 |
| 「更多」 | 換源、重新取得本章、書籍詳情、全域系統設定：留，都是動作 |

### 朗讀與語音

語速、音調、語音引擎、音色：留。「音量」拿掉：和系統的媒體音量是同一件事，引擎音量固定滿格。

### 關於夜讀

開源與法律：GitHub、開源許可證、免責聲明、隱私說明、權限（權限狀態加用途）。系統工具：更新紀錄、崩潰日誌、自動更新（不自動／自動檢查／Wi-Fi 下自動下載，原本是兩個開關）、接收測試版更新、啟動時檢查書架更新、清除網頁資料（原本三個按鈕）。

### 書架

整理選單（排序：自訂、最近閱讀、加入時間、更新時間、書名；網格／列表；統一封面；選取）、加入選單（搜尋書籍、加入本地書籍、從檔案或網址匯入書架、匯出書架）、長按書本（書籍詳情、選取、檢查更新、自動檢查更新、移出書架）：留，都是動作或一列選擇，沒有重複的控制。

### 搜尋

精準搜尋、搜尋範圍、排序：留。結果篩選留「只看已加入書架」「作者包含」與書源；「只看有封面」「分類包含」拿掉：封面有沒有是書源給不給的事，分類字樣各書源寫法不一，用它篩常常篩掉想看的書。

### 書源管理

書源的匯入、編輯、校驗、分組與除錯是工具頁，給要自己整理書源的人用，不在這次盤點的範圍；裡面的欄位照 Legado 的書源格式，拿掉會讓書源讀不懂。

## Consequences

- 改過被拿掉的設定（骨架、俐落平移、朗讀音量、搜尋的封面與分類篩選）的人回到預設；舊的偏好值留在手機上但不再讀。
- 習慣在閱讀器面板調字距、上下邊距、自動翻頁速度或點擊區域的人，要多一步進閱讀偏好。
- 新增設定時照上面的分級規則放；要在閱讀器面板加項目，先確認是邊讀邊會調的，不然放閱讀偏好。
