# Triage 標籤

技能用五個標準的 triage 角色溝通。這個檔案把角色對應到本 repo issue tracker 實際使用的標籤字串。

| mattpocock/skills 的標籤 | 本 tracker 的標籤 | 意思 |
| ------------------------ | ----------------- | ---- |
| `needs-triage`           | `needs-triage`    | 維護者需要評估這個 issue |
| `needs-info`             | `needs-info`      | 等回報者補充資訊 |
| `ready-for-agent`        | `ready-for-agent` | 規格完整，可以交給 AFK agent |
| `ready-for-human`        | `ready-for-human` | 需要人來實作 |
| `wontfix`                | `wontfix`         | 不會處理 |

技能提到某個角色時（例如「套上 AFK-ready 的 triage 標籤」），用這張表裡對應的標籤字串。

右欄可以改成實際使用的詞彙。
