# 書源與網路 (source_network)

## Responsibility
- 擁有全應用 HTTP 傳輸的唯一出口與反爬對策：以 `lib/core/services/network_service.dart:13` 的 `NetworkService` 單例封裝全域 `Dio`（`connectTimeout=15s/receiveTimeout=15s`），透過 `lib/core/network/interceptors/app_interceptor.dart:6` 的 `AppInterceptor` 補 `Referer/User-Agent/Accept-Language` 並以 `onError:61` 接管 301/302/303/307/308 手動重定向（`_maxManualRedirects=10`、跨域剝離 `Authorization/Cookie`、`manualRedirectChain` 寫 `extra`），以及 `lib/core/network/interceptors/lenient_cookie_manager.dart:12` 的 `LenientCookieManager` 容錯 `expires=session`/`max-age=session` 並以 `_setCookieReg=8` 拆分逗號黏連的 `Set-Cookie`，網路層的 `StrResponse:4` 則以 `raw.extra['_manualRedirectChain']` 暴露重定向鏈供上層判定 `isRedirect`。
- 擁有書源模型的執行期健康語意與校驗編排：以 `lib/core/models/source/book_source_logic.dart:4` 的 `sourceRuntimeStatusTags`/`SourceHealthCategory`/`SourceRuntimeHealth` 定義 `異常/搜尋失效/目錄失效/正文失效/校驗超時/已隔離/非小說源/需要登入` 等 16 個分組標籤的優先序與 `allowsSearch/allowsReading/cleanupCandidate/quarantined` 四維語意，並由 `lib/core/services/check_source_service.dart:427` 的 `CheckSourceService` 以 `8` 併發工作者、`_SourceCheckExecutionPool:351` 的同域與 JS 雙重訊號量、`SourceValidationContext.runNonInteractive` 非互動 Zone、`lib/core/services/source_check_isolate.dart:113` 的 `Isolate.spawn` 隔離執行完整 `搜尋→發現→詳情→目錄→正文` 五階段探測，將結果寫回 `BookSource.bookSourceGroup/bookSourceComment/lastUpdateTime` 並以 `EventBus.checkSourceDone` 廣播。
- 擁有書源 CRUD 與管理面互動：`lib/features/source_manager/source_manager_provider.dart:241` 的 `SourceManagerProvider` 承載 `BookSourceDao.getAllPart/getByUrl` 的列表、分組/搜尋/排序/批次選取、匯入預覽（`SourceImportService.parseSourcesDetailedAsync:86` 以 `compute` 背景解析）、校驗觸發與 `canReorder/isMutationBusy` 互斥；`lib/features/source_manager/source_editor_page.dart:12` 的 `SourceEditorPage` 以 6 個 `Tab`（基礎/搜尋/發現/詳情/目錄/正文）編輯 `BookSource` 規則；`lib/core/services/source_debug_service.dart:29` 的 `SourceDebugService` 以 `StreamController<DebugLog>.broadcast` 串流 `state 1/10/20/30/40/1000/-1` 的分階段除錯日誌。
- 擁有換源與輔助能力：`lib/core/services/source_switch_service.dart:34` 的 `SourceSwitchService` 以 `Pool(6)` 併發搜尋候選源、`resolveSwitch` 水合新書詳情/目錄並以 `transaction` 原子落盤；`lib/core/services/rate_limiter.dart:15` 的 `ConcurrentRateLimiter` 按 `BookSource.concurrentRate` 的 `延遲` 或 `次數/毫秒` 雙模式限流；`lib/core/services/rule_big_data_service.dart:9` 的 `RuleBigDataService` 以 `md5(bookUrl)/md5(key)` 檔案分流超大變數；`lib/core/services/backstage_webview.dart:9` 的 `BackstageWebView` 以隱藏 `WebViewController` 承載 `javaScript/sourceRegex/overrideUrlRegex/delayTime` 的渲染型請求；`lib/core/services/encoding_detect.dart:9` 與 `lib/core/services/chinese_utils.dart:6` 分別提供 GBK/UTF-8/UTF-16 的位元組編碼偵測與 OpenCC 簡繁轉換。

## Boundaries
- **網路層為唯一出口，不繞過攔截鏈**：所有書源相關 HTTP 必須經 `NetworkService.dio`（`lib/core/services/network_service.dart:22`），禁止新建 `Dio()` 或 `http.get` 直連；`AppInterceptor` 的 `Referer/User-Agent/Accept-Language` 與 `LenientCookieManager` 的 `Set-Cookie` 容錯為線上反爬最小集，移除或改為 `dio_cookie_manager` 原生 `CookieManager` 會使 `expires=session` 站點登入態丟失；`HttpClient.client` 僅為 `NetworkService().dio` 別名（`lib/core/services/http_client.dart:12`），禁止在其上另加攔截器。
- **批次校驗必須在非互動 Zone 內且限 Isolate**：`CheckSourceService.check:510` 強制 `SourceValidationContext.runNonInteractive` 包裝，`_IsolateSourceChecker` 內 `AnalyzeUrl.getStrResponse` 的 `useWebView` 衛語依賴 `isNonInteractive` 阻斷 `HeadlessWebViewService/BackstageWebView`，禁止在校驗路徑為單章提速而啟動 `WebView`；`lib/core/services/source_check_isolate.dart:141` 的 `errorsAreFatal:false` 與 `NetworkService.init(ephemeral:true):36` 為硬約束，禁止在背景改用 `PersistCookieJar` 或 `Isolate.run`（`flutter_js` FFI 無法跨 isolate，見 `engine` 模組註解），`JsEngine.clearCaches/JsExtensionsBase.clearCaches:536` 必須在批次前後各一次，禁止為「快取命中」而保留 `ttfCache/fontReplaceCache`。
- **健康狀態以分組標籤為唯一持久化契約**：`BookSource.bookSourceGroup` 的逗號分隔標籤與 `bookSourceComment` 的 `// Error:` 前綴為校驗結果的唯二落盤欄位（`lib/core/models/source/book_source_logic.dart:119` 的 `addGroup/removeGroup/removeInvalidGroups/addErrorComment` 為唯一寫入口），禁止新增獨立 `healthStatus` 欄位或改 `sourceRuntimeStatusTags` 的字面量（`搜尋失效/發現失效/.../已隔離/非小說源`）而不提供 `SharedPreferences`/`AppCache` 遷移；`lastUpdateTime=DateTime.now().millisecondsSinceEpoch:756` 與 `respondTime=0` 在校驗收尾固定刷新，禁止按階段差異化寫入。
- **`customOrder` 為書源排序唯一鍵**：`SourceManagerProvider.canReorder:339` 的 5 條件（`sortMode==0&&!sortDesc&&!groupByDomain&&filterGroup==全部&&searchQuery.isEmpty`）與 `reorderSource:795`/`moveSelectedToTop:638`/`moveToTop:674` 的 `BookSourceDao.updateCustomOrder` 為排序唯一契約，禁止在 `BookSource` 新增 `orderWeight` 或在 `BookSourceDao` 加 `ORDER BY weight` 而不經 `canReorder` 守衛，否則拖曳與 `sortMode=1(weight)` 語意衝突；`SourceImportService._prepareImportSources:196` 對新源的遞增 `nextOrder=maxOrder+1` 為併發不安全但線上僅單線匯入，禁止為「併發匯入」而加鎖改為 `MAX(customOrder)+1` 的 DB 聚合（會破壞 `isRegistered` 測試替身）。
- **`concurrentRate` 與 `isNovelTextSource` 為書源作者語意**：`TocRule.preUpdateJs/formatJs`、`ContentRule.replaceRegex/webJs`、`BookSource.concurrentRate` 的 `延遲/次數/毫秒` 雙模式（`lib/core/services/rate_limiter.dart:44`）與 `bookSourceType==0` 純文字約束（`lib/core/models/source/book_source_logic.dart:169`）皆為書源顯式語意，引擎與校驗必須原樣尊重，僅在 `lib/core/services/source_check_isolate.dart:1265` 的頭尾探測與 `lib/core/services/check_source_service.dart:882` 的 `payloadMapContainsRuleJs` JS 分類處做最小相容，禁止新增「自動重排序」或「封面/音訊源自動隔離」等全域改寫。
