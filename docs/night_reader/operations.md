## Known Risks
- **SharedPreferences 的字串契約無遷移**：`SettingsProvider._migrateLegacySettings:206` 僅收斂 `ttsSource != system → system` 單例，`PreferKey` 的 `cPrimary='colorPrimary'/cNPrimary='colorPrimaryNight'`、`bgImage/bgImageN` 等歷史命名（`settings_provider.dart:132`）若更名即孤兒化，且 `BackupService.config.json:92` 會把全量 `prefs.getKeys()` 打進備份，還原時 `RestoreService._restorePreferences:165` 按型別回寫會把已改名的舊 key 重新寫回，造成幽靈偏好與 `AppConfig` 靜態鏡像漂移。

## Boundaries
- **備份 ZIP 的目錄與命名不可改扁平**：`BackupService.createBackupZip:30` 明定 `backupTempDir/legado_backup/` 為中間目錄（兼容 Legado 舊備份），`ZipFileEncoder.addFile(entity)` 保留此子目錄前綴，`RestoreService:50 _normalizedFileName(p.basename)` 正是為此做歸一，改為扁平打包或改 `backup-YYYY-MM-DD.zip` 命名需同時改 `RestoreService.supportedFiles:100` 的別名表與 `p.basename` 歸一，且舊備份仍含 `legado_backup/`，不可僅發新不讀舊。
- **manifest 的 schemaVersion 為唯一閘門**：`BackupService.currentSchemaVersion:27 → AppDatabase().schemaVersion` 與 `RestoreService._isManifestCompatible:192(schemaVersion is int && <= AppDatabase().schemaVersion)` 構成「新備份可還入舊庫？否，舊備份可還入新庫？是」的單向契約，`AppDatabase.schemaVersion` 升級時不得在 `RestoreService` 放寬為 `manifest==null → true`，否則無 `manifest` 的第三方 ZIP 會繞過相容檢查而 `Model.fromJson` 以寬鬆 `??'' / toInt` 寫入 `NOT NULL` 欄位致 `constraint failed`。
- **偏好的字面量 key 不可重命名**：`PreferKey` 的 `themeMode/language/userAgent/threadCount/replaceEnableDefault/ttsSpeechRate/Pitch/Volume/coverSearchPriority` 等與 `ThemeSettingsProvider:28 theme_app_*_v1/theme_reader_*_v1/update.ignored_version` 為跨版本持久化契約，重命名需同時提供 `SharedPreferences` 舊 key 遷移與 `BackupService.config.json` 的舊備份重映射，否則舊用戶與舊備份的設定永久孤兒化（同 `app_shell.md:79` 對 `PreferKey/AppPattern` 的破壞性變更警告一致）。
