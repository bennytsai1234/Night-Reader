# 漫畫

設計原則與否決過的方向在根目錄的 `DESIGN.md`；決定與理由在 ADR 0052。閱讀畫面的手感與細節照 Mihon 的條漫閱讀器（`ui/reader/viewer/webtoon/`），這裡寫的是要照的值與夜讀刻意不同的地方。

## 閱讀畫面

- **只有圖**：一章的圖由上往下接成一長條，撐滿寬度、左右不留白、圖與圖之間不留縫、不裁白邊。平常不顯示章名、頁碼或頁首頁尾（Mihon 預設顯示「8 / 24」，夜讀不照）；點一下叫出閱讀選單才看到章名、本話第幾張與全書進度。
- **底色**是目前正文風格的閱讀底色（深色用純黑時是黑），不照 Mihon 預設的黑。
- **紙色**：深色時每張圖乘上讀者在漫畫偏好選的紙色：原色（預設，不染）、暖灰 `#C9C1B3`、宣紙 `#D8CCAE`、深灰 `#A39C90`。白底變成那個顏色，黑線條照樣黑，網點與灰階照比例一起暗，不成負片；彩頁一起染，透明的地方維持透明。純黑開不開都染；淺色時一律原色。只染圖，換章分隔、失敗畫面、骨架與底色不動。畫圖時一起乘（`BlendMode.modulate`），不另開一層。
- **縮放**：雙指 0.5×–3×，放大時可以拖動平移。點兩下：原本大小時以點的位置放大到 2×，其他大小時回到原本大小；動畫 200ms。
- **點擊區域**照「閱讀偏好」的九格（和文字閱讀器同一個值，`reader.md`「閱讀器選單」；預設九格都是喚起選單，不照 Mihon 的 L 形）：上一頁、下一頁是往上、往下捲四分之三屏；上一章、下一章是上一話、下一話，到頭時提示「已經是第一話」「已經是最後一話」；目錄、自動翻頁（自動捲動）、日夜切換同選單上那幾顆鈕；朗讀在漫畫沒有字可念，當成喚起選單。選單開著時點哪裡都是收起。慣性滑動或自動捲動中按下去只停下來，放開不算點擊。
- **音量鍵翻頁**：「閱讀偏好」的音量鍵翻頁開著時同文字閱讀器（只在 Android）：下是往下捲四分之三屏、上是往上，「反向」對調；自動捲動中按了先停下。選單或目錄開著、漫畫還沒開好時，音量鍵照常調音量。
- **換章分隔**：一章最後一張圖下面接一塊，上下各留 128、左右 32，置中兩段字：「已閱畢：」加這一章的章名、「接下來：」加下一章的章名（照 Mihon 的 `ChapterTransition`：標題 17、章名 20 最多五行，兩段之間 24，最寬 460）；沒有下一章時寫「以下空白」，第一話上面寫「已達盡頭」與「這一章：」第一話的章名。中間缺章時多一行提醒缺幾章。下一章還沒抓好時，在這塊顯示狀態與「重試」。繼續往下捲就進下一章，選單裡的章名與進度跟著換。
- **預載**（ADR 0061）：照文字閱讀器分兩層、範圍固定，不看捲動速度。圖片清單先拿目前這一話前後各 2 話，拿到的接上條漫；畫面上下各 3000 點以內的圖先讀好、解碼好，離開範圍就放掉。順序是畫面上的、往下的（近的先）、往上的；預載同時最多 3 張，要畫的那張馬上開始。預載時載不到的圖不顯示失敗，捲到時再試一次；先拿時載不到的圖片清單，預載範圍伸到那一話時再試一次。
- **圖還沒到**：已下載的章節記著每張圖的寬高，一開始就是正確高度。捲到時還沒解碼好的先畫固定比例的骨架（照骨架呼吸），圖到了淡入；在畫面外就解碼好的直接畫，不淡入。高度和骨架不同時，畫面頂端看到的內容不動：變的那張在畫面頂端以上，捲動位置跟著補回去（捲動中照原本的速度接著滑）；在下面就只把它下面的往下推（Mihon 是每張先佔一個螢幕高、顯示下載百分比，夜讀不照）。開書接回上次在那張的幾成時圖還沒到，讀者還沒動之前那張圖到了，照新高度停在同一成。轉螢幕、改視窗寬度時圖照新寬度變高，畫面頂端停在同一張的同一成；頂端是換章分隔時停在分隔的同一成，不跳到下一話，慣性滑動也一起停下、不照舊座標接著滑。
- **載入失敗**：那一張佔約八成螢幕高，中間寫原因，下面「重試」與「用網頁開啟」；其他張照常。網路漫畫按「重試」不用之前暫存的那一張、照書源重抓（同 Mihon）；下載好的話與本地漫畫照舊讀。整話載不下來時在換章分隔寫原因與「重試」；整本打不開時畫面中間寫原因與「重試」。
- **要登入、要在網頁上驗證才讀得到**（ADR 0038）：上面三處失敗都多一顆實心的「登入」或「前往驗證」排第一，「重試」退成文字鈕、「用網頁開啟」不顯示；登入資料有變或從驗證頁回來就重抓失敗的那一張、那一話或重開。

## 閱讀選單

- 沿用文字閱讀器的選單外框與進出場（`reader.md`「閱讀器選單」），左側一樣有亮度條（只在 Android）：位置、進出場、加暗段整個畫面疊黑都同文字閱讀器，調的是同一個亮度與「最暗程度」。
- **上方**：章節卡寫章名與書源；右上角「更多」：換源、重新取得本章、登入（登入後重抓載不下來的話）、書籍詳情、全域系統設定；本地漫畫的前三項、沒有登入的書源的登入灰掉。本地漫畫的書源膠囊同本地書寫「本地」、不能點。
- **下方**：圓鈕（自動捲動、日夜切換）；上一話、本話第幾張的進度條、下一話；目錄、漫畫偏好。沒有替換規則、朗讀、定時朗讀、排版。目錄面板頂端同文字閱讀器是「目錄｜書籤｜標註」，漫畫沒有書籤與標註，後兩段灰掉。
- **漫畫偏好**：「自動捲動速度」，下面一組「深色時的紙色」：四個 52 的圓色票，紙色上一個黑色的「漫」（染完的樣子），下面寫名稱，選中的框是強調色；同文字閱讀器挑正文風格的色票。選擇記在整個 App（不是每本書），跟著閱讀設定同步與備份；淺色時整排灰掉、不能按。最後一張是點擊區域的九格卡片，和「閱讀偏好」同一個元件、同一個值，最後一列「恢復預設」；卡片外不加標題（ADR 0076）。打開時上下選單與亮度條收起，面板關掉後回到選單打開的樣子（同 `reader.md`「面板」）。

## 書架

- 漫畫和小說在同一個書架，書卡一樣、不加標記，點開進漫畫閱讀器；進度線照讀到第幾話。統一封面時畫預設封面的漫畫變體（`components.md`「預設封面」）。
- 「整理」選單的「排序與篩選」有篩選：全部、小說、漫畫、有聲書；書架上沒有的那一類、或只有一種書時灰掉。
