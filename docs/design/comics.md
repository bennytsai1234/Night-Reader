# 漫畫

設計原則與否決過的方向在根目錄的 `DESIGN.md`；決定與理由在 ADR 0052。閱讀畫面的手感與細節照 Mihon 的條漫閱讀器（`ui/reader/viewer/webtoon/`），這裡寫的是要照的值與夜讀刻意不同的地方。

## 閱讀畫面

- **只有圖**：一章的圖由上往下接成一長條，撐滿寬度、左右不留白、圖與圖之間不留縫、不裁白邊。平常不顯示章名、頁碼或頁首頁尾（Mihon 預設顯示「8 / 24」，夜讀不照）；點一下叫出閱讀選單才看到章名、本話第幾張與全書進度。
- **底色**是目前風格的閱讀底色（深色用純黑時是黑），不照 Mihon 預設的黑。
- **縮放**：雙指 0.5×–3×，放大時可以拖動平移。點兩下：原本大小時以點的位置放大到 2×，其他大小時回到原本大小；動畫 200ms。
- **點擊區域**照 Mihon 的 L 形：上排與左中往上捲一屏，右中與下排往下捲一屏，正中間叫出選單。
- **換章分隔**：一章最後一張圖下面接一塊，上下各留 128、左右 32，置中兩段字：「已閱畢：」加這一章的章名、「接下來：」加下一章的章名（標題用 titleMedium、章名用 bodyMedium）；沒有下一章時寫「以下空白」，往上捲到第一章之前寫「已達盡頭」。中間缺章時多一行提醒缺幾章。下一章還沒抓好時，在這塊顯示狀態與「重試」。繼續往下捲就進下一章，選單裡的章名與進度跟著換。
- **圖還沒到**：已下載的章節記著每張圖的寬高，一開始就是正確高度。還沒下載到的先畫固定比例的骨架（照骨架呼吸），圖到了淡入；高度和骨架不同時只調整畫面外的那幾張，看得到的位置不動（Mihon 是每張先佔一個螢幕高、顯示下載百分比，夜讀不照）。
- **載入失敗**：那一張佔約八成螢幕高，中間寫原因，下面「重試」與「用網頁開啟」；其他張照常。

## 閱讀選單

- 沿用文字閱讀器的選單外框與進出場（`reader.md`「閱讀器選單」）。
- **上方**：章節卡寫章名與書源；右上角「更多」：換源、重新取得本章、書籍詳情、全域系統設定（本地漫畫只有後兩項）。
- **下方**：圓鈕（自動捲動、日夜切換）；上一話、本話第幾張的進度條、下一話；目錄、漫畫偏好。沒有替換規則、朗讀、定時朗讀、排版。

## 書架

- 漫畫和小說在同一個書架，書卡一樣、不加標記，點開進漫畫閱讀器；進度線照讀到第幾話。統一封面時畫夜空的漫畫變體（`components.md`「預設封面」）。
- 「整理」選單有篩選：全部、小說、漫畫、有聲書；書架上只有一種書時不出現。
