# 網站與 README

設計原則與否決過的方向在根目錄的 `DESIGN.md`。

## 網站

`website/` 是給路過的人看的一頁，不是推廣：不寫行銷文案、不放使用者數或星星，也不放免責聲明。

- **只有一套配色**，不分淺深：背景是兩張同構圖的整幅山景，固定不位移，往下捲從黃昏慢慢入夜（5%–85%），月亮與星星入夜才出來；字從頭到尾是月光色，內容不墊玻璃。
- **內容照路過的人想知道的排**：開頭一句講夜讀讀什麼，接著 13 個功能一路排下去、不分段不取段名，只講別的閱讀器沒有或做得不一樣的事。「夜讀不附書源」一定要講，只講怎麼找、怎麼一鍵導入，不寫書源網站的站名。
- **字**：每個功能一個功能名（「朗讀」「統一封面」）加一句說明，句尾不加句號；不寫標語、不用修辭當標題。
- **版型**：開頭左字右手機；每個功能一列，手機與字一左一右。導覽膠囊只放圖示與「下載」。
- **畫面**：用 App 真的畫面（`test/screens/website_shots_test.dart`），正文字放大、兩側留白；能用前後對照證明的用切換鈕。手機框寬 393、高 760，純黑邊框。
- **短片**：講到會動的功能才放，捲到時只播一次，播完停在最後一幀，右下角重播鈕，不循環。
- **下載**：月光色小卡（App 圖示加「下載夜讀」與版本、大小），旁邊只多一個「iOS 未簽章檔」連結。

## README

`README.md` 是 GitHub 上的門面，內容跟著網站走：13 個功能與字句都和網站一樣，網站改字時一起改。

- **畫面全做成圖**（GitHub 不吃樣式）：開頭、下載各一張卡片，功能分四張卡片、各一排手機（`docs/readme/`，由 `tool/readme_art/` 從網站的天空、手機框與 App 畫面拍出來），字和手機都排在卡片裡；GitHub 淺色、深色看到同一張圖。
- **卡片會動**：講到會動的功能，手機螢幕裡放網站的短片；版面不變的輪換（風格、統一封面）由左而右掃過去換；版面會動的前後對照（隱藏廣告、正文整理）先淡到只剩紙色、再淡入另一頁，免得兩頁的字疊在一起。多台同步在那一格裡由手機的外框變形成平板、畫面同樣先淡到紙色再換成平板版，停一下再變回手機（使用者 2026-11-08 選定）。短片每秒 30 幀，壓縮不讓字糊掉。一張卡片 6 秒一輪、不停循環。開頭那支手機第一幀就是書架（GitHub 手機版與連結預覽常只顯示第一幀）。
- **圖以外的字**：開頭圖下一行「下載 Android 版・網站・更新說明」；iOS 安裝方式、書源與本地書收在可以點開的兩段；回報、開發文件、致謝、授權與一句免責收成最後三行小字。
