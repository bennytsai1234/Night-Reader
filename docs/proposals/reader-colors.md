# App 的顏色和閱讀器的顏色分開

使用者 2026-11-19 要的：現在一個風格同時套到 App 介面、閱讀正文與閱讀選單（ADR 0040），要改成兩邊各自選。分支 `feat/reader-colors`。做完改 ADR 0040、`docs/design/appearance.md`「風格與強調色」「風格卡」、`GLOSSARY.md`「風格」，刪掉這份。

## 1. 閱讀器也淺色、深色各選一個風格（討論中）

- 改前：淺色、深色各選一個風格，App 與閱讀器一起用。
- 改後：App 淺色、深色各一個；閱讀器淺色、深色另外各一個。深淺（跟隨系統／淺色／深色）照舊全 App 共用，閱讀器的月亮鈕切換的也還是它。
- 理由：ADR 0040 分淺深的原因（白天晚上想看不同的紙）在閱讀器一樣成立；深淺分開會變成第三組設定，沒人提過。

## 2. 哪些畫面算閱讀器那一邊（討論中）

| 畫面 | 跟哪一邊 |
|---|---|
| 閱讀器：正文、上下選單、目錄面板、外觀與排版、朗讀、標註面板 | 閱讀器 |
| 漫畫閱讀器（底色、選單、漫畫偏好） | 閱讀器 |
| 在閱讀器裡打開的彈出選單、動作表、提示框 | 閱讀器（蓋在正文上；「提示框照 App 的配色」在閱讀器裡指閱讀器那一邊的介面配色） |
| 從閱讀器推進去的整頁（書籍詳情、閱讀偏好、換源、替換規則） | App（它們是一般的頁面） |
| 有聲書播放器 | App（沒有紙，本來就照 App 的介面配色） |
| 系統啟動畫面 | App（開 App 進的是書架） |

## 3. 閱讀器的風格在哪裡選（討論中）

- 改前：「外觀與主題」的兩排風格卡與閱讀器「外觀與排版」的色票改的是同一個設定。
- 我目前傾向：「外觀與主題」的兩排只改 App；閱讀器的風格只在「外觀與排版」的色票改，改的是目前深淺那一個（要改另一個深淺，按月亮鈕切過去再選）。一個設定一個控制（DESIGN.md 原則 5），邊讀邊調的放閱讀器面板。
- 風格卡的樣子不變：卡上畫的是那個風格的紙與字，代表的是風格本身。

## 4. 強調色、純黑、玻璃效果兩邊共用（討論中）

- 改前：全 App 一個強調色、一個「深色用純黑」、一個玻璃效果。
- 我目前傾向：照舊共用，都在「外觀與主題」。純黑一個開關管住所有深色（ADR 0040 的理由），閱讀器想要有色的深色底時關掉純黑、選紙墨或茶褐。

## 5. 升級與還沒選過的人（討論中）

- 閱讀器沒選過風格時用 App 的風格：舊使用者升級後畫面不變；新使用者在「外觀與主題」換風格，閱讀器也跟著換，直到在閱讀器裡選了一個。淺色、深色各自算。
- 不在升級時把 App 的風格複製一份給閱讀器：同步時兩台各自複製出來的那份會被當成新的改動，可能蓋掉另一台在閱讀器裡已經選好的。

## 觸點（docs/agents/new-feature.md）

- 同步：閱讀器的淺色、深色風格加進設定同步。備份與還原：偏好設定整份備份，自動帶上；還原沒有這兩項的舊備份時，還原只寫備份裡有的設定：這台在閱讀器選過的留著，沒選過的跟著備份裡的 App 風格。
- 其餘不適用：不碰書源、找書、書架、下載、進度、通知、隱私、iPhone（同一套程式）。README 與網站寫的「六種風格，白天、晚上各選一個」照樣成立。
- 漫畫、有聲、本地書：漫畫閱讀器跟閱讀器；有聲書播放器跟 App；本地書和網路書同一個閱讀器。
