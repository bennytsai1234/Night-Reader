# 單章借源

對應 `PLAN.md`「單章借源」。主書源只有某一章壞掉（防盜章、只有半章、抓不到）時，從別的書源只借這一章的正文存進本機，原本的書源與目錄不動。全新功能線，定案前每一項都要有答案（`docs/agents/new-feature.md`）；定案後寫成 ADR，「觸點」一節照第 11 項。

狀態：討論中＝還在談；已定＝使用者說可以；已做＝分支上做好了。

## 查到的事實

- **Legado 有這個功能**，叫「單章換源」：閱讀選單的「換源」分成「單章換源」「書籍換源」兩項。單章換源和書籍換源用同一套搜尋、各自的清單；點一個書源打開它的目錄、捲到估計的那一章（照章名相似度、章號），使用者自己點一章，抓到的正文直接蓋進主書源這一章的快取，不記是借來的、閱讀器也不標。
- **夜讀的正文**存在資料庫，一章一筆，照「書源網址＋書的網址＋章節網址」認。存在這個位置的正文，閱讀器照讀、書架自動下載當成已下載不再抓、備份會帶（書架上的書）、匯出 TXT 會用；同步一律不帶（同步沒有正文）。
- **會把這一章換回主書源版本或刪掉的**：閱讀選單「更多 → 重新取得本章」（向主書源重抓、抓到才蓋掉）、書籍詳情「清除已下載」（刪掉後書架自動下載從主書源重抓）、換源（舊書源的正文全刪）、移出書架或沒加入書架就離開（正文跟著書刪）、書架檢查更新時主書源把這一章換了網址（借來的那筆對不上、從新網址重抓）。
- **還沒擋住的**：閱讀器預載或書架自動下載正在向主書源抓這一章時借源，主書源的結果晚到會蓋掉借來的正文（存正文時不看那一章是不是已經有了）。
- **防盜章、半章抓得到**，閱讀器照常顯示，不會走到失敗畫面；只有「抓不到」才會出現失敗畫面或提示。
- **換源面板**的搜尋與清單可以共用，但現在的開法綁著整本換源（文案、關掉面板後照樣換完），借源要另一種開法。面板列的是啟用、同一類（加聚合源）的書源，回得快的在前、抓到目錄才列。
- **校驗的「只抓到第一頁」判斷**要用抓那一章時的每個請求，平常抓正文沒有留，借一章時要另外接。現成能直接用的檢查是換源那一條：正文「讀得到」（拿掉插圖後至少 20 字、不是失敗訊息）。
- **章節裡的插圖**：抓正文時順便用那個書源抓圖、存進這本書的插圖資料夾；連不上的之後由書架自動下載用**主書源**補，還原備份後也是用主書源重抓。

## 1. 借來的正文放哪裡（討論中，其他幾項跟著它）

- **A. 直接蓋進主書源這一章的位置，不記是借來的**（Legado 的做法）。資料表不改。
- **B. 蓋進同一個位置，另外記「借自哪個書源」**。要改資料表（高風險的資料庫），備份格式跟著改；換來的是閱讀器標得出「借自哪裡」、重新取得本章可以改向借的書源重抓、插圖補得到。

| | 改前 | A | B |
|---|---|---|---|
| 這一章讀到的 | 主書源的壞章 | 借來的 | 借來的 |
| 書架自動下載 | — | 不碰（已經有正文） | 不碰 |
| 重新取得本章 | 向主書源重抓 | 換回主書源的版本 | 可以選向哪個重抓 |
| 清除已下載、移出書架 | 刪掉 | 借來的一起刪 | 同左 |
| 備份 | — | 帶（同其他正文） | 帶，要改格式 |
| 另一台手機 | — | 讀主書源的（同步不帶正文） | 同左 |
| 閱讀器標不標 | — | 標不出 | 標得出 |

我目前傾向 **A**：照 Legado、資料表不動；要換回主書源就按「重新取得本章」，這正好是主書源修好時的出路。

## 2. 入口（討論中）

- **閱讀選單「更多」**：在「換源」後面加一項「單章借源」，借的是目前這一章。防盜章、半章都開得起來，這是一定要有的入口。
- **開書失敗的按鈕列**（重試、換源、返回那一排）：加「單章借源」，借的是開不起來的那一章；目錄是空的、抓不到目錄時沒有章可借，灰掉。
- **跳章或捲到下一章取不到時的提示**：取不到時會回到原本那一章，「更多」借到的會是原本那一章，所以提示旁放一顆「借源」，借的是取不到的那一章；提示已經有「登入」「前往驗證」時，那兩顆優先。
- 目錄長按：夜讀的目錄沒有長按，不加。

我目前傾向三個都做。

## 3. 候選怎麼找、怎麼排（討論中）

和換源面板同一套搜尋與清單：同樣的書源範圍（同一類加聚合源）、同樣的排序（回得快的在前），每列照舊寫「共 N 章」；頁首寫「單章借源」。選了書源之後再核對一次它的書名、作者，以及抓完詳情後是不是小說（聚合源要看這一步）。

## 4. 怎麼確定借到的是同一章（討論中）

換源換錯了看得到，借錯一章只會悄悄存進去，所以要比換源嚴。

- **A. 照 Legado**：點一個書源，打開它的目錄、捲到估計的那一章（先比章名、再比章號，同換源的對法）並標出來，使用者自己點一章才借。分卷標題、付費章節不能點。
- **B. 自動對章名**：章名對得上就直接借，對不上才打開目錄（同 A）。缺點是「番外」「感言」這類好幾章同名時會借錯而看不出來。

不論哪種，借之前都要正文「讀得到」；「讀得到」不等於「完整」，半章、防盜章這種讀得到的分不出來，借完使用者自己看，不對就換一個書源再借，或按重新取得本章換回來。

我目前傾向 **A**：多點一下，但借的一定是使用者看過章名的那一章。

## 5. 借的時候怎麼抓、怎麼存（討論中）

- 用借的書源那本書與那一章抓正文；同一章的下一頁停止點用借的書源目錄裡的下一章，不拿主書源的。
- 存進主書源這一章的位置，主書源目錄的章名、字數這類不改（Legado 會改字數，夜讀不改）。
- 主書源預載或書架自動下載晚到的結果不蓋掉借來的：只有使用者明確的動作（借源、重新取得本章）換得掉已存的正文，自動補抓只補還缺的章。這一條改的是存正文的共用地方，下載、預載、匯出補抓都經過。
- 寫進去之前再看一次：主書源這一章還在目錄裡、不是付費章節、使用者沒有關掉閱讀器或改選別的；關面板、離開閱讀器、再選一次都取消還沒寫進去的那次。
- 插圖用借的書源抓好；連不上的照現狀留給書架自動下載補，但補的是主書源，多半補不到，那幾張就不畫（同其他抓不到的插圖，ADR 0050）。不另改「確定抓不到」的記法。
- 借的書源抓那一章要登入或網頁驗證時，照 ADR 0038 在面板裡給「登入」「前往驗證」，開的是借的書源，回來重抓同一章。

## 6. 借完之後（討論中）

- 借的是目前這一章：閱讀器照目前的位置重排這一章（同重新取得本章）。借的是開書失敗或跳章取不到的那一章：開書失敗照「重試」重開，跳章取不到的跳到那一章。畫面換好才提示「已從 書源名 借來本章」。
- 書籤、標註照錨點找回同一句，找不到照比例估；改得多時標註可能畫到別句（同替換規則改了正文時）。
- 朗讀正在念這一章時，照正文改了的現狀先停下，下次開始念借來的。
- 全書進度照下次開書重算（每章多長照已存正文的大小）。
- 閱讀器頂端的書源膠囊照舊開主書源這一章的網頁。

## 7. 借來的是暫時還是固定（討論中）

跟著第 1 項：固定存著，跟著這本書已下載的正文一起留、一起刪（「查到的事實」第三條那幾種情況）。主書源之後修好了不會自動換回（夜讀分不出修好沒有），要使用者自己按重新取得本章。

## 8. 付費章節（討論中）

- 主書源這一章是付費章節：閱讀器本來就跳過、看不到這一章，「更多」借不到它；整本都是付費章節時開書失敗頁的「單章借源」灰掉（ADR 0059）。
- 借的書源那一章是付費章節：目錄上點不了，抓的時候也擋（ADR 0057）。
- 不碰「不接付費內容」的界線：借的是別的書源的免費正文，不是購買。

## 9. 同步、備份、匯出（討論中）

- 同步：不做。同步本來就不帶正文，另一台讀到的還是主書源那一章，要在那台再借一次。閱讀進度照常同步，但同步只帶「第幾章第幾個字」，兩台這一章的正文長短不同時，另一台會停在不同的句子。
- 備份與還原：照現狀帶，不用改（第 1 項選 A 時）；還原時備份裡那一版蓋掉這台的。
- 匯出 TXT、書架匯出：照現狀用存著的正文，含借來的。

## 10. 各類書（討論中）

- 小說：做。
- 漫畫：不做。漫畫的章是一包圖檔，要用借的書源的請求格式抓每張圖、打包，走的是另一條下載；先看小說用起來怎樣。
- 有聲書：不做。音訊網址多半有時效、不存成正文，借來的網址過幾天就失效。
- 本地書：不適用（沒有書源）。入口灰掉（同換源）。

## 11. 觸點（討論中，定案後搬進 ADR）

| 觸點 | 我目前傾向的答案 |
|---|---|
| 書源類型、匯入時怎麼分 | 不適用 |
| 書源校驗怎麼判斷抓得到 | 只看「讀得到」，同換源（第 4 項） |
| AI 修書源 | 不適用：借源不改書源 |
| 要登入、要網頁驗證 | 照 ADR 0038：在面板裡給借的書源的「登入」「前往驗證」（第 5 項） |
| 付費章節 | 照 ADR 0057（第 8 項） |
| 搜尋 | 不適用：用換源面板的搜法 |
| 發現 | 不適用 |
| 換源 | 做：和換源面板共用搜尋與清單（第 3 項）；換源時借來的正文跟舊書源的一起刪 |
| 手機上的檔案匯入 | 不適用 |
| 書架 | 不做：書卡不加標記 |
| 書籍詳情 | 照現狀：已下載的章數、清除已下載、匯出都把借來的當成這一章 |
| 下載 | 做：自動補抓不蓋掉已存的正文（第 5 項）；書架自動下載不碰借來的（ADR 0008） |
| 清除已下載、移出書架 | 照 ADR 0008：借來的一起刪 |
| 檢查新章節 | 照現狀：主書源把這一章換了網址時，借來的那筆對不上，從新網址重抓 |
| 閱讀器失敗時的畫面 | 做：開書失敗的按鈕列、跳章取不到的提示（第 2 項） |
| 偏好、設定 | 不做：沒有開關（ADR 0030） |
| 進度 | 照現狀，另一台可能停在不同句子（第 9 項） |
| 閱讀統計 | 照現狀：照書名、作者、類別記 |
| 書籤、標註、朗讀 | 照 ADR 0042、0044 的錨點；朗讀照現狀先停（第 6 項） |
| 通知、鎖定畫面 | 不適用：在前景做，不是背景工作 |
| 同步 | 不做（第 9 項） |
| 備份與還原 | 照現狀帶（第 9 項） |
| 匯出、和 Legado 互通 | 照現狀：匯出 TXT 與書架匯出含借來的；Legado 備份格式不受影響 |
| `PRIVACY.md` 與「隱私說明」 | 不改：只向使用者自己的書源送搜尋、目錄、正文與插圖的請求，同換源 |
| `README.md`、網站 | 不做：不新增宣傳項目 |
| `GLOSSARY.md` | 做：加「單章借源」 |
| `docs/design/` | 做：`reader.md` 的「更多」、失敗畫面與提示，`screens.md` 的借源面板 |
| iPhone | 照常：前景的操作，用同一套書源引擎；兩個正式建置都要過 |
| 自動巡檢 | 做：新檔案排進所在資料夾的分段（`docs/agents/auto-audit.md`） |

## 這次不做

借源後標出「借自哪裡」（第 1 項選 A 時做不到）、主書源修好時自動換回、借來的章同步到另一台、漫畫與有聲書、整本借（那就是換源）。
