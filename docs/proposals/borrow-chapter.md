# 單章借源

對應 `PLAN.md`「單章借源」。主書源只有某一章壞掉（防盜章、只有半章、抓不到）時，從別的書源只借這一章的正文存進本機，原本的書源與目錄不動。全新功能線，定案前每一項都要有答案（`docs/agents/new-feature.md`）；定案後寫成 ADR，「觸點」一節照第 10 項。

狀態：討論中＝還在談；已定＝使用者說可以；已做＝分支上做好了。

## 查到的事實

- **Legado 有這個功能**，叫「單章換源」：閱讀選單的「換源」分成「單章換源」「書籍換源」兩項。單章換源列出其他書源搜到的同一本書（和書籍換源同一份清單），點一個書源打開它的目錄、捲到估計的那一章（照章名相似度、章號），使用者自己點一章，抓到的正文直接蓋進主書源這一章的快取，不記是借來的、閱讀器也不標。
- **夜讀的正文**存在資料庫，一章一筆，照「書源網址＋書的網址＋章節網址」認。存在這個位置的正文，閱讀器照讀、書架自動下載當成已下載不再抓、備份會帶（書架上的書）、同步一律不帶（同步沒有正文）。
- **會把這一章換回主書源版本的**：閱讀選單「更多 → 重新取得本章」（向主書源重抓、抓到就蓋掉）、書籍詳情「清除已下載」（刪掉後書架自動下載從主書源重抓）、換源（舊書源的正文全刪）。其他自動流程不會刪或蓋已存的正文（ADR 0008）。
- **防盜章、半章抓得到**，閱讀器照常顯示，不會走到失敗畫面；只有「抓不到」才會出現失敗畫面或提示。
- **換源面板**可以只拿「使用者選的書源＋它已經抓好的目錄」，不一定要換源，借源可以直接用同一個面板。面板列的是啟用、同一類（加聚合源）的書源，回得快的在前；全部書源搜完約 80～95 秒，邊搜邊列。
- **校驗的「只抓到第一頁」判斷**要用校驗時記下的每個請求，平常抓正文沒有記，借一章時用不上。現成能用的檢查只有換源用的那一條：正文「讀得到」（不是空的、不是只有一兩行）。
- **章節裡的插圖**：抓正文時順便用那個書源抓圖、存進這本書的插圖資料夾；之後沒抓到的圖，書架自動下載會用**主書源**再補。

## 1. 借來的正文放哪裡（討論中，其他幾項跟著它）

- **A. 直接蓋進主書源這一章的位置，不記是借來的**（Legado 的做法）。資料表不改。
- **B. 蓋進同一個位置，另外記「借自哪個書源」**。要改資料表（高風險的資料庫），備份格式跟著改；換來的是閱讀器標得出「借自哪裡」、重新取得本章可以改向借的書源重抓。

| | 改前 | A | B |
|---|---|---|---|
| 這一章讀到的 | 主書源的壞章 | 借來的 | 借來的 |
| 書架自動下載 | — | 不碰（已經有正文） | 不碰 |
| 重新取得本章 | 向主書源重抓 | 換回主書源的版本 | 可以選向哪個重抓 |
| 清除已下載 | 刪掉、從主書源重抓 | 同左，借來的也沒了 | 同左 |
| 備份 | — | 帶（同其他正文） | 帶，要改格式 |
| 另一台手機 | — | 讀主書源的（同步不帶正文） | 同左 |
| 閱讀器標不標 | — | 標不出 | 標得出 |

我目前傾向 **A**：照 Legado、資料表不動；要換回主書源就按「重新取得本章」，這正好是主書源修好時的出路。

## 2. 入口（討論中）

- **閱讀選單「更多」**：在「換源」後面加一項「單章借源」，借的是目前這一章。防盜章、半章都會開得起來，這是一定要有的入口。
- **開書失敗的按鈕列**（重試、換源、返回那一排）：加「單章借源」，借的是開不起來的那一章。
- **跳章取不到時的提示**：跳章失敗會回到原本那一章，「更多」裡借到的會是原本那一章、不是取不到的那一章；要借取不到的那一章，只能在提示旁放一顆「借源」（提示已經有「登入」「前往驗證」時，那兩顆優先）。
- 目錄長按：夜讀的目錄沒有長按，不加。

我目前傾向前三個都做。

## 3. 候選怎麼找、怎麼排（討論中）

直接用換源面板：同樣的搜法、同樣的書源範圍（同一類加聚合源）、同樣的排序（回得快的在前），每列照舊寫「共 N 章」；頁首寫「單章借源」。

## 4. 怎麼確定借到的是同一章（討論中）

換源換錯了看得到，借錯了一章只會悄悄存進去，所以要比換源嚴。

- **A. 照 Legado**：點一個書源，打開它的目錄、捲到估計的那一章，使用者自己點。
- **B. 自動對章名**：章名對得上（繁簡、空白不同也算，同自動換源）就直接借；對不上才打開它的目錄讓使用者點（同 A）。
- **C. 只對章名**：對不上的書源灰掉、不能點。

不論哪種，借之前都要正文「讀得到」（同換源）；付費章節不借（第 7 項）。半章、防盜章這種「讀得到但不完整」的分不出來，借完使用者自己看，不對就換一個書源再借，或按重新取得本章換回來。

我目前傾向 **B**：多半一點就好，對不上時還有 Legado 的退路。

## 5. 借完之後（討論中）

- 抓正文時下一頁的停止點用借的書源目錄裡的下一章；借的書源的章節資料（字數、章節網址這類）不寫進主書源的目錄。
- 插圖用借的書源抓好；這次連不上的圖記成抓不到，不讓書架自動下載之後用主書源一直補（補不到會讓下載任務每天失敗一次）。
- 存好後面板收起，閱讀器照目前的位置重排這一章（同重新取得本章），提示「已從 書源名 借來本章」。這一章的書籤、標註照錨點找回同一句，找不到照比例估（同換源）。

## 6. 借來的是暫時還是固定（討論中）

跟著第 1 項：固定存著，直到使用者按重新取得本章、清除已下載或換源。主書源之後修好了不會自動換回（夜讀分不出修好沒有），要使用者自己按重新取得本章。

## 7. 付費章節（討論中）

- 主書源這一章是付費章節：閱讀器本來就跳過、看不到這一章，入口不會出現；就算借了也存不進去（付費章節不存正文，ADR 0057）。
- 借的書源那一章是付費章節：抓不到，提示「付費章節」，換別的書源。
- 不碰「不接付費內容」的界線：借的是別的書源的免費正文，不是購買。

## 8. 同步、備份（討論中）

- 同步：不做。同步本來就不帶正文，另一台讀到的還是主書源那一章，要在那台再借一次。閱讀進度照常同步，位置照錨點對。
- 備份：照現狀帶，不用改（第 1 項選 A 時）。

## 9. 各類書（討論中）

- 小說：做。
- 漫畫：不做。漫畫的章是一包圖檔，要用借的書源的請求格式抓每張圖、打包，走的是另一條下載；先看小說用起來怎樣。
- 有聲書：不做。音訊網址多半有時效、不存成正文，借來的網址過幾天就失效。
- 本地書：不適用（沒有書源）。入口灰掉（同換源）。

## 10. 觸點（討論中，定案後搬進 ADR）

| 觸點 | 我目前傾向的答案 |
|---|---|
| 書源類型、匯入時怎麼分 | 不適用 |
| 書源校驗怎麼判斷抓得到 | 照換源：只看「讀得到」；校驗的半章判斷借一章時用不上（第 4 項） |
| AI 修書源 | 不適用：借源不改書源 |
| 要登入、要網頁驗證 | 照 ADR 0038：借的書源要登入或驗證才抓得到時提示原因，換別的書源；不在面板裡開登入 |
| 付費章節 | 照 ADR 0057（第 7 項） |
| 搜尋 | 照換源面板的搜法，不另做 |
| 發現 | 不適用 |
| 換源 | 做：用同一個面板（第 3 項）；換源時借來的正文跟舊書源的一起刪 |
| 手機上的檔案匯入 | 不適用 |
| 書架、書籍詳情 | 不做：不加標記 |
| 下載、清除已下載 | 照 ADR 0008：書架自動下載不碰已存的；清除已下載連借來的一起清 |
| 檢查新章節 | 不適用：目錄照主書源 |
| 閱讀器失敗時的畫面 | 做：開書失敗的按鈕列、跳章取不到的提示（第 2 項） |
| 偏好、設定 | 不做：沒有開關（ADR 0030） |
| 進度、閱讀統計 | 照現狀：進度記在主書源這一章，統計照書名 |
| 書籤、標註、朗讀 | 照 ADR 0042、0044：照錨點找回同一句；朗讀念借來的正文 |
| 通知、鎖定畫面 | 不適用：在前景做，不是背景工作 |
| 同步 | 不做（第 8 項） |
| 備份與還原 | 照現狀帶（第 8 項） |
| 匯出、和 Legado 互通 | 匯出 TXT 照存著的正文，含借來的；和 Legado 互通不適用 |
| `PRIVACY.md` 與「隱私說明」 | 不改：只向書源的網站送請求，同換源 |
| `README.md`、網站 | 待定：要不要列成功能 |
| `GLOSSARY.md` | 做：加「單章借源」 |
| `docs/design/` | 做：`reader.md` 的「更多」與失敗畫面、`screens.md` 的換源面板 |
| iPhone | 照常：前景的操作，兩邊一樣 |
| 自動巡檢 | 不新增資料夾或服務時不用排；新檔案照所在資料夾的分段 |
