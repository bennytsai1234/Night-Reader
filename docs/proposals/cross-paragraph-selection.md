# 正文跨段選字

對應 `PLAN.md`「正文跨段選字」：現在選字只能選在同一段裡，想複製、標註或分享跨兩段以上的文字做不到；讓選取可以從一段拉到另一段。

## 現況（查過程式）

- 長按選一個詞，拖兩端的把手延伸；把手拖出這一段就停在段落邊上，拉不到別段。
- 用手指捲動正文會收掉選取；所以選取只能在畫面上看得到的那一段裡調。
- 標註本身的畫法並不限一段：開頭照錨點找回、往後畫記下的那麼長，每一行各畫一塊。「只在一段裡」只是因為選字選不出跨段的範圍。標註畫多長，看的是記下的字有幾個，所以記下的字一定要和正文裡那段字一模一樣（含段落之間的分隔）。
- 匯出已經會把多行的標註寫成多行引用。
- 替換規則是對整章（一行一段、行與行之間有換行）套用，規則裡含換行也比對得到；Legado 從選字新增替換規則時，就是把跨段的字連換行一起放進規則。

## 各項

### 1. 跨到哪裡為止（已做）

- 改前：只能在長按的那一段裡。
- 提議：同一章裡任意跨段，到章首（章名不算）、章末停住，不跨到下一章。
- 理由：標註與書籤都記「第幾章＋章內第幾個字」，跨章要拆成兩筆記錄、清單與匯出也要跟著拆，牽動太大；跨章的需求可以分兩次選。

### 2. 把手拖到畫面外（已做，開始捲的位置討論中）

- 改前：把手只能在畫面上那一段裡移動，捲動就收掉選取。
- 提議：拖著把手超出正文區上緣或下緣時，正文自己捲，超出越多越快，手指回到正文區或放開就停；到章首、章末停。手感照 Flutter 內建選字（SelectionArea）的邊緣自動捲動：超出的距離最多算到 20，乘上同一個速度係數。用手指捲動照舊收掉選取。
- 跟著要處理：開頭或結尾捲出畫面時，那一端的把手不畫；選單放在畫面上看得到的那一段選取的上方（或下方）。
- 被否決：手指捲動時保留選取（像手機瀏覽器）。
- 停的地方：這一章的第一行或最後一行整行出現在畫面上就不再捲（只看選取端點不夠：手指的水平位置落在最後一行中間時選取到不了章末，正文會一直捲進下一章）。
- 討論中：照 Flutter 的做法，手指要拖出正文區才開始捲。正文區外面只有頁首、頁尾那一條：預設上下各約 24，夠拖到最快；關掉頁首、頁尾時上面只剩挖孔的高度（沒有挖孔的手機是 0），下面只剩 4，幾乎捲不動。另一種做法是正文區上下緣往裡一段（例如 40）就開始捲，越靠邊越快，頁首頁尾開不開都一樣。

### 3. 複製、搜尋、分享給其他 App 時段落之間接什麼（已做）

- 改前：只會有一段，不用接。
- 提議：複製與分享給其他 App（翻譯、字典）時段落之間接一個換行（同 Legado）；搜尋時換成一個空格。

### 4. 跨段時的「隱藏」「替換」（已做）

- 改前：只有一段，照選取位置逐字對齊找出原文寫成規則。
- 定案（使用者 2026-11-23 選 B，照 Legado）：規則連段落之間的換行一起比對。選到整段時那幾段整個不見；只選到前一段的後半和後一段的前半時，剩下的兩半會接成一段。
- 規則的原文照現在的方法逐段對齊取出，段與段之間放規則套用時那兩段之間真正的字（通常是一個換行，原文有空行時連空行一起），這樣才比對得到。
- 選取跨過一張插圖時「隱藏」「替換」灰掉、留在原位（這條與下一條的名稱寫法是實作時定的預設）：插圖在規則看到的字裡是一個記號，寫進規則會把圖一起藏掉，而且只對這一章有效。
- 其他照現在：不是正則、套用到所有書、排在既有規則之後、提示可「復原」；規則名稱與提示裡的段落之間換成一個空格。「替換」的即時測試放選到的那幾段原文。
- 被否決：跨段時灰掉（一行一行藏）。

### 5. 跨段的標註怎麼畫、怎麼列（已做）

- 畫法：每一行各畫一塊，段落之間的段距留空，看得出原本的分段（現有畫法本來就這樣，不用改）；淺色、深色各畫一張圖確認。
- 記下的字：照正文裡的那段字原樣記，段落之間的分隔一起記，清單與匯出才分得出段落；已經畫好的標註不受影響，資料格式不變。
- 畫多長：現在是「從開頭往後畫記下的那麼多個字」，段落之間的分隔也算字。正文沒變時照這樣畫剛好；打開或關掉「重新分段」、換源後分段不同時，段落分隔的數目一變，結尾就多畫或少畫兩個字。改成「往後數，段落分隔不算，數到記下的字數為止」：只差在分段時結尾照樣對；正文沒變時和現在畫得一模一樣，一段裡的標註也完全不變。正文的字本身改了（重新分段也會補引號、增減空格）時，開頭照舊靠錨點找、結尾照舊估，不保證對齊，這點和現在一樣。ADR 0044 否決「記開頭與結尾兩個錨點」那一條一起改寫成跨段的說法。
- 點標註：點到的字落在標註畫到的範圍才算，和畫法用同一個範圍，點到段距或插圖不算。
- 清單（閱讀器目錄面板「標註」頁、「我的 → 書籤與標註」、點標註打開的面板）：段落之間換一行、不空行，清單最多三行時不浪費一行在空白上。
- 匯出：一個標註仍是一段引用，引用裡照原本的分段分成幾段（現有的匯出已經這樣寫，不用改）；備忘照舊接在後面。
- 面板裡的「複製」：同第 3 項，段落之間一個換行。
- 同步、備份、換源：記下的字照舊放在原本的欄位，換行跟著走，資料庫與搬移流程不用改。還沒更新的另一台照開頭加長度畫，正文相同時畫得一樣準，清單也顯示得出來；分段不同時結尾差幾個字，和那台現在的算法一樣。

### 6. 書籤（已做）

- 位置照舊：留在選取開頭那一句，跳回時從整句讀起；不用改。
- 清單顯示：照舊從那一句開頭顯示到選取結尾（選得比一句長時含選到的全部），跨段時同第 5 項，段落之間換一行。那一句照開頭所在的那一段切，不照長按的那一段。

## 要留意的地方

- 畫面外那幾段的排版會被丟掉，只留畫面附近的；現在算選取的框時會跳過沒排好的段，回傳的第一個、最後一個框不一定是真的開頭、結尾。把手要各自照真的開頭、結尾找位置，不在畫面上就不畫；反白與選單只照畫面上看得到的那一段算。標註畫跨好幾屏的長段也一起確認。
- 自動捲動：每一步都確認還在這一章裡（只限制選取端點不夠，畫面仍可能滑進下一章）；捲到同一章還沒排好的地方先等排好再算游標，手指停在邊緣不動時也跟著捲動重算；捲動中不掉幀（設計原則 1），鄰章照常預先載入。放手、取消手勢、手指捲動、返回、開閱讀選單、蓋紙、跳章、換內容、開始朗讀或自動翻頁、離開閱讀器時，選取與排著的捲動一起作廢，停下後照常存閱讀進度。
- 現在選取的框一時算不出來（那一段還沒排好）時，整個選取層會先不畫，連帶拖著的把手也消失、拖曳被中斷；自動捲動時這種空檔會變多，拖著的那一端要一直留著。
- 書籤的那一句與「隱藏」「替換」找原文，現在都照長按的那一段算；開頭拖到別段後要改照開頭（或整個選取）所在的那一段，不然會在錯的段落裡找。
- 兩端拖到重疊時現在往旁邊留一個字，跨段後可能留到段落分隔或拆開一個表情符號；兩端一律停在真的字上，以整個字為單位。
