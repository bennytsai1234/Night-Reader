# 全部設定盤一遍

`docs/proposals/roadmap.md` 第 8 項的清單：整個 App 使用者看得到、能改、改了會被記住的每一個設定，各給一個建議（留、拿掉、合併、搬），由使用者勾。勾了的這一波做掉，沒勾的不動。規則照設定分級與去留的 ADR 0030，加上之後各份寫明「使用者點名要」的 ADR。

## 檔頭

- **讀的版本**：`beta` 的 `fff55f9c`（2026-11-24）。
- **狀態**：盤點中斷（額度用完）。已盤完：外觀與主題、閱讀偏好、朗讀與語音、閱讀器裡的面板與選單。目前盤完的每一列都建議留，還沒有拿掉、合併或搬的。
- **還沒盤的頁**（存的鍵已經數完，每頁有哪些照下面列的寫成列）：
  - AI 服務：服務網址、金鑰、模型、找書的模型、思考程度（都在 `ai_repair.service` 一筆）、同時修幾個網站（`ai_repair.concurrency`）。
  - AI 找書：深度（`ai_find.depth`）、本數（`ai_find.count`）、不想看的（`ai_find.avoid`）。
  - 備份與同步：同步空間（`sync.space`、`sync.google.account`、`sync.webdav.*`）。
  - 關於夜讀：離開時蓋住畫面、解鎖才能打開（`app_cover_on_leave`、`app_lock_mode`，還沒發過，ADR 0083）、自動更新（`update.auto_check`、`update.auto_download_unmetered`）、接收測試版更新（`update.beta_channel`）、啟動時檢查書架更新（`auto_refresh`）。
  - 每本書：自動檢查更新（`canUpdate`，書架長按與書籍詳情兩處）、本書套用替換規則（`useReplaceRule`）、重新分段（`reSegment`，閱讀器「更多」與替換規則面板兩處，測試版 v0.4.2-beta.14 起，ADR 0078 使用者要兩處）、換封面與編輯資訊（`customCoverUrl`、`customIntro` 等）、書架上的自訂順序（`order`）。
  - 「不是使用者看得到的設定」一節：內部狀態與快取（書架、閱讀器、書源管理、發現、搜尋的上次畫面紀錄，同步的裝置代號與紀錄，更新的略過版本，崩潰紀錄，`downloads_paused_all`、`orphaned_books_switched` 等）、搬舊資料的鍵、沒有畫面能改的舊鍵（`showAddToShelfAlert`、`bookshelf_show_last_update`、`replaceEnableDefault`、`userAgent`、`reader_padding_horizontal`、`reader_tts_language` 等），以及 `prefer_key.dart` 裡約一百個從 Legado 帶來、程式從沒讀過的鍵。

### 怎麼數的

1. **從存的地方數**，不從畫面數：
   - 偏好設定：`lib/core/constant/prefer_key.dart` 的每一個鍵，加上程式裡直接寫字串或另外定義的鍵（全 `lib/` 搜尋偏好設定的讀寫呼叫與 `…Key = '…'` 的常數，跨行的寫法另搜一次）；閱讀設定另照 `ReaderSettings.all` 的 44 項逐一對。
   - 每本書：`Books` 表的欄位與內嵌的 `ReadConfig`（重新分段、本書套用替換規則等）。
   - 每個書源：`BookSources` 表使用者能改的欄位（啟用、啟用發現、分組、順序、類型）。
   - 同時對過三份清單，確定沒有漏掉的鍵：同步的清單（`SettingsSync.keys`）、備份時跳過的鍵（`BackupService.deviceOnlyKeys`）、`v0.4.1` 到現在新加的鍵（`git diff v0.4.1 HEAD -- lib`）。
   - Android、iOS 原生端沒有另外存設定；開 App 的系統啟動畫面底色是照外觀設定算出來的，不另存。
2. **每個鍵對到一列**，或列進最後的「不是使用者看得到的設定」：內部狀態、快取、上次的位置、只用來搬舊資料的鍵，以及沒有任何畫面能改的舊鍵。
3. **一列是一個存下來的值**：同一個值在兩個地方都能改時只算一列，「在哪」寫兩處（例如字號在閱讀器面板與閱讀偏好）。一列裡的選項不另算（ADR 0030 第 5 條），所以點擊區域的九格是一列、頁首頁尾的四欄是一列、亮度條連同「跟隨系統」是一列。反過來，存成一筆的幾個值在畫面上是各自一列、各改各的時，照畫面分列（AI 服務的網址、金鑰、模型、找書的模型、思考程度）。
4. **進過正式版了沒**：在各正式版 tag（`v0.3.5`～`v0.4.1`）裡找這個設定的字樣或存的鍵，寫第一個有它的版本；`v0.3.5` 之前的不再往回找，寫「v0.3.5 或更早」。只在測試版出現過的寫是哪一個測試版起；連測試版都還沒發過的寫「還沒發過」。
5. **這個月加的多半已經進了正式版**：`v0.4.1` 是 2026-11-23 發的，對比、正文另選風格、分頁列、介面語言、AI 找書的本數都在裡面。還沒進正式版的只有四個：重新分段（測試版）、漫畫深色時的紙色（測試版）、離開時蓋住畫面、解鎖才能打開（兩個都還沒發過）。
6. **建議怎麼下**：拿掉或合併要說得出是哪一條規則；ADR 寫明使用者點名要的一律留；拿不準的寫留，問題放「拿不準」。

## 拿不準

- **「音量鍵翻頁」＋「反向」、「隱藏系統狀態列」＋「一起隱藏導覽列」要不要各合成一列三選一**：ADR 0030 第 3 條說「其中一個只在另一個開著時有用，合成一列三選一」；但這兩個子開關是使用者列的第一批（ADR 0043 開頭），ADR 0059 也說設定頁依賴開關的子設定照舊隱藏。照「使用者點名的一律留」先寫留。合併的話：改前兩列，改後一列「音量鍵翻頁：關｜音量下翻下一頁｜音量上翻下一頁」與一列「隱藏：都不隱藏｜只隱藏狀態列｜狀態列與導覽列」。
- **漫畫偏好的「自動捲動速度」和閱讀偏好的自動翻頁「速度」是同一個值**：在漫畫裡調了，文字書的自動翻頁也跟著變，兩處的名字也不一樣。不確定是刻意共用還是該分開。
- **書籍詳情的「換封面」與「編輯資訊」的封面欄改的是同一個值**：兩種改法（挑一張與填網址），照 Legado 都有；還沒查 Legado 是不是也這樣，先算留。
