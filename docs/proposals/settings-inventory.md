# 全部設定盤一遍

整個 App 使用者看得到、能改、改了會被記住的每一個設定，各給一個建議（留、拿掉、合併、搬），由使用者勾。勾了的照做，沒勾的不動。規則照設定分級與去留的 ADR 0030，加上之後各份寫明「使用者點名要」的 ADR。

## 檔頭

- **讀的版本**：`beta` 的 `fff55f9c`（2026-11-24）；盤完時 `beta` 的 `lib/` 和它一樣。
- **狀態**：盤完。共 104 個設定：建議留 103 個、拿掉 1 個、合併 0 個、搬 0 個；拿不準 3 條（每條都寫了改前改後，勾了就照改後做）。

### 怎麼數的

1. **從存的地方數**，不從畫面數：
   - 偏好設定：`lib/core/constant/prefer_key.dart` 的每一個鍵，加上程式裡直接寫字串或另外定義的鍵（全 `lib/` 搜尋偏好設定的讀寫呼叫與 `…Key = '…'` 的常數，跨行的寫法另搜一次）；閱讀設定另照 `ReaderSettings.all` 的 44 項逐一對。
   - 每本書：`Books` 表的欄位與內嵌的 `ReadConfig`（重新分段、本書套用替換規則等）。
   - 每個書源：`BookSources` 表使用者能改的欄位（啟用、啟用發現、分組、順序、類型）。
   - 同時對過三份清單，確定沒有漏掉的鍵：同步的清單（`SettingsSync.keys`）、備份時跳過的鍵（`BackupService.deviceOnlyKeys`）、`v0.4.1` 到現在新加的鍵（`git diff v0.4.1 HEAD -- lib`）。
   - Android、iOS 原生端沒有另外存設定；開 App 的系統啟動畫面底色是照外觀設定算出來的，不另存。
2. **每個鍵對到一列**，或列進最後的「不是使用者看得到的設定」：內部狀態、快取、上次的位置、只用來搬舊資料的鍵，以及沒有任何畫面能改的舊鍵。
3. **一列是一個存下來的值**：同一個值在兩個地方都能改時只算一列，「在哪」寫兩處（例如字號在閱讀器面板與閱讀偏好）。一列裡的選項不另算（ADR 0030 第 5 條），所以點擊區域的九格是一列、頁首頁尾的四欄是一列、亮度條連同「跟隨系統」是一列。反過來，存成一筆的幾個值在畫面上各自能選時照畫面分列（AI 服務的網址、金鑰、模型、找書的模型、思考程度）；一起填、按一次連線才存的一組帳號算一列（WebDAV 的網址、帳號、密碼）。編輯資訊的欄位建議相同的併一列（書名、作者、簡介），不同的分列。
4. **進過正式版了沒**：在各正式版 tag（`v0.3.5`～`v0.4.1`）裡找這個設定的字樣或存的鍵，寫第一個有它的版本；`v0.3.5` 之前的不再往回找，寫「v0.3.5 或更早」。只在測試版出現過的寫是哪一個測試版起；連測試版都還沒發過的寫「還沒發過」。
5. **這個月加的多半已經進了正式版**：`v0.4.1` 是 2026-11-23 發的，對比、正文另選風格、分頁列、介面語言、AI 找書的本數都在裡面。還沒進正式版的只有四個：重新分段（測試版）、漫畫深色時的紙色（測試版）、離開時、新書預設套用替換規則的開關。
6. **建議怎麼下**：拿掉或合併要說得出理由：ADR 0030 的哪一條規則，或照 Legado、改了看不到效果；ADR 寫明使用者點名要的一律留；拿不準的寫留，問題放「拿不準」。

## 建議拿掉、合併或搬的

- **拿掉「編輯資訊」的「自訂標籤」欄**（每本書，已做，#634）：編輯資訊七欄，填過的標籤留在資料裡、照舊同步，只是畫面上不再出現；Legado 的編輯頁也沒有這欄。

合併、搬：沒有。另外三個可能要合併或拿掉的放在「拿不準」，由使用者挑。

## 拿不準

- **「音量鍵翻頁」＋「反向」、「隱藏系統狀態列」＋「一起隱藏導覽列」要不要各合成一列三選一（不做）**：ADR 0030 第 3 條說「其中一個只在另一個開著時有用，合成一列三選一」；但這兩個子開關是使用者列的第一批（ADR 0043 開頭），ADR 0059 也說設定頁依賴開關的子設定照舊隱藏。照「使用者點名的一律留」先寫留。合併的話：改前兩列，改後一列「音量鍵翻頁：關｜音量下翻下一頁｜音量上翻下一頁」與一列「隱藏：都不隱藏｜只隱藏狀態列｜狀態列與導覽列」。
- **漫畫偏好的「自動捲動速度」和閱讀偏好的自動翻頁「速度」是同一個值（不做，維持共用）**：在漫畫裡調了，文字書的自動翻頁也跟著變，兩處的名字也不一樣。不確定是刻意共用還是該分開，先寫留。改前：一個值、兩處能改。改後二選一：維持共用（不動）；或分成漫畫、文字書各一個值，這是多一個新設定，記在 `PLAN.md`「新功能」。
- **「離開時」一列四選一（已做，#634）**：開了解鎖，蓋住畫面一定跟著開、灰掉，和 ADR 0030 第 3 條（一個開關只在另一個開著時有用，合成三選一）是同一類，只是方向反過來；兩列都是 ADR 0083 定的，使用者 2026-11-24 選了這兩項。現在合成一列「離開時：不蓋｜蓋住畫面｜蓋住並解鎖才能打開｜蓋住，離開 5 分鐘後要解鎖」，存的值照原本兩個換算，讀它們的程式不改。
- **編輯資訊裡 Legado 沒有的三欄：分類、來源名稱、目錄 URL（不做，三欄留著）**：Legado 的編輯頁只有書名、作者、類型、封面、簡介（`BookInfoEditActivity`，類型在夜讀照書源定、不能改）；夜讀從第一版就多了這三欄，改了都看得到效果，所以寫留。編輯資訊七欄（書名、作者、分類、封面、來源名稱、目錄 URL、簡介）；這三欄也拿掉就剩 Legado 的四欄。目錄 URL 改錯，這本書就抓不到目錄。
